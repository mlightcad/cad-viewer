# CAD Diff Viewer Example

Vanilla TypeScript host for [`@mlightcad/cad-diff-viewer`](../cad-diff-viewer).
The page supplies one parent `div`; the component creates both canvases.

```bash
pnpm --filter @mlightcad/cad-diff-viewer-example dev
```

Then open the printed local URL (default `http://localhost:5173`).
