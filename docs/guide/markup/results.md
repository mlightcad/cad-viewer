# View Results

View and manage all markups in the current drawing.

## Markup Panel

Open the **Review** panel to see the complete list of markups. Each entry shows:

- Markup type (Arrow, Cloud, Text, etc. icons)
- Author
- Creation time
- Optional: a summary of the markup text content

## Select and Locate

- Click a markup in the panel → the canvas automatically **focuses** (zooms to that markup's position)
- Click a markup on the canvas → the corresponding entry is highlighted in the panel

## Edit Metadata

Some markups can have their **Comment** (note) and **Status** (state, such as Open / Resolved) metadata edited in the panel.

## Show / Hide

- You can toggle the visibility of individual markups in the panel
- The markup visibility button on the status bar can show/hide all markups at once

## Clear

- Clear a single item: select it and press **Delete**
- Clear all: click "Clear All" in the panel
- Clearing can be undone

## Import / Export

The top of the panel provides export and import buttons; the sidecar JSON file can be shared across drawings and devices.
