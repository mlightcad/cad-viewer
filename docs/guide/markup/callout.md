# Callout

A standalone combination of a leader line and a text bubble, used to annotate a detail from a distance.

## Interaction Steps

1. Click to select the arrow **tip** end (pointing to the annotated position)
2. Drag to place the text bubble **anchor** position—a real-time preview of the leader + bubble is shown
   - **Smart attach**: if the first point lands on an existing cloud / rectangle / circle frame line, that shape is automatically reused and only the leader and bubble are added
3. Enter text in the bubble

## Three Grip Points

- **tip**: arrow endpoint; drag to adjust the pointing direction
- **anchor**: bubble endpoint; drag to adjust the bubble position
- **midpoint**: moves both tip and anchor together, panning the whole callout

Double-click the bubble text to enter inline editing.
