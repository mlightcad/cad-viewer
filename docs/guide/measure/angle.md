# Angle

Measure the angle formed by three points (vertex → first side → second side).

## Interaction Steps

1. Click to select the angle **vertex**
2. Click to select a point on the **first side**
3. Click to select a point on the **second side**

## Preview

After step 2 is complete, a dashed arm1 + solid arm2 rubber band + an angle badge are shown.

## Angle Calculation

Uses the included angle (interior angle), range 0° ~ 180°.

## Display

The angle badge is placed along the angle bisector, above the vertex.

## After Creation

All three points have grips; dragging any one recalculates the angle.
