# Arc Length

Measure the length of an arc. Two modes are supported.

## Auto-Lock Mode (Recommended)

When the first point lands on an existing CIRCLE, ARC, or polyline bulge in the drawing, lock mode is automatically entered:

- The cursor is constrained to the circle / arc
- A circular snap indicator is shown
- The arc is automatically generated along the sweep direction of the mouse

**Ctrl** flips between the major arc / minor arc direction.

## Three-Point Free Mode

When the first point is not on any arc, three-point mode is automatically entered:

1. Start point
2. Pass-through point
3. End point—a real-time preview of the arc is shown

## Display

The arc is drawn on the canvas, plus an arc-length badge.

## After Creation

The endpoint grips can be dragged to adjust.
