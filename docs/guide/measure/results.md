# View Results

View and manage all measurement results in the current drawing.

## Measurement Panel

Open the **Measure** panel to see the complete measurement list. It can be filtered by type:

- All
- Distance
- Angle
- Area
- Arc Length
- Coordinates

Each entry shows:

- Type icon
- Measurement value (with unit)
- Layout it belongs to

## Select and Locate

- Click a measurement in the panel → the canvas automatically zooms to that measurement's position
- Click a measurement on the canvas → the corresponding entry is highlighted in the panel

## Show / Hide

- The measurement visibility button on the status bar can show/hide all measurements at once
- After hiding, the measurement data is still retained; it is only visually invisible

## Clear

- Clear a single item: select it and press **Delete**
- Clear all: "Clear All" button at the bottom of the panel
- Clearing can be undone
