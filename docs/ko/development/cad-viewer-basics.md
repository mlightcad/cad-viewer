# CAD Viewer 기본

이 프로젝트는 사용자를 위해 `cad-viewer`와 `cad-simple-viewer` 두 가지 뷰어를 제공합니다. 어떤 뷰어를 선택할지는 프로젝트 요구 사항과 원하는 통합 수준에 따라 달라집니다:

## **cad-viewer**를 사용해야 하는 경우:

- 현대적인 UI, 대화상자, 툴바 및 상태 관리를 갖춘 **바로 사용할 수 있는 Vue 3 컴포넌트**를 원하는 경우.
- 최소한의 설정으로 고성능 CAD 뷰어/편집기를 Vue 애플리케이션에 신속하게 포함하고자 하는 경우.
- 파일 로딩, 렌더링, 레이어/엔티티 관리 및 사용자 상호 작용을 기본으로 처리하는 솔루션을 선호하는 경우.
- 최적화된 SVG 및 THREE.js 렌더러, 국제화 및 테마와의 원활한 통합을 원하는 경우.
- **직접** UI를 처음부터 구축하고 싶지 **않은** 경우.

**권장 대상:** 세련된 사용자 인터페이스로 CAD 파일을 표시해야 하는 대부분의 웹 애플리케이션, 대시보드 또는 플랫폼.

## **cad-simple-viewer**를 사용해야 하는 경우:

- UI 프레임워크 의존성 없이 **핵심 CAD 로직만**(문서 관리, 명령 스택, 렌더링 엔진 통합) 필요한 경우.
- **자신만의 사용자 정의 UI**를 구축하거나 CAD 기능을 Vue가 아닌 또는 웹이 아닌 환경에 통합하고자 하는 경우.
- 대용량 CAD 파일을 처리하기 위한 최대한의 유연성과 성능이 필요하며, 로직을 자신의 렌더링 또는 UI 계층에 연결할 계획인 경우.
- 필수 CAD 작업 및 캔버스 렌더링만 제공하는 프레임워크 독립적인 솔루션을 원하는 경우.

**권장 대상:** 사용자 정의 통합, 헤드리스 CAD 처리 또는 고도로 맞춤화된 CAD 솔루션을 구축하는 고급 사용자.

**요약 표:**

| 패키지              | UI 제공 여부 | 프레임워크 | 사용 사례                                      |
|---------------------|-------------|-----------|-----------------------------------------------|
| `cad-viewer`        | 예          | Vue 3     | 현대적인 UI를 갖춘 턴키 CAD 뷰어/편집기         |
| `cad-simple-viewer` | 아니오      | 없음      | 사용자 정의 또는 헤드리스 용도를 위한 핵심 CAD 로직 |

자세한 내용은 [**Simple CAD Viewer 통합**](./integrate-simple-cad-viewer) 및 [**CAD Viewer 컴포넌트 통합**](./integrate-cad-viewer-component)을 참조하십시오.
