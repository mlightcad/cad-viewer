# 면적 측정

여러 점으로 둘러싸인 다각형의 면적을 측정합니다.

## 상호작용 단계

1. 첫 번째 점 클릭
2. 이후 꼭지점을 순서대로 클릭—실시간으로 반투명 채우기 + 점선 윤곽선 미리보기
3. **Enter** 또는 **Esc** 키로 종료, 또는 첫 번째 꼭지점 근처를 클릭하면 자동으로 닫힘

## 닫힘 조건(자동 닫기)

- 클릭 위치가 시작점에서 약 14px 이내
- 클릭 위치가 현재 마지막 꼭지점에 매우 가까움
- 새 선분이 기존 선분을 가로지름(자기 교차 형성 시 자동 닫기)

## 면적 계산

슈레이스 공식(Shoelace Formula)을 사용합니다.

## 표시

면적 배지는 다각형의 무게중심 위치에 있습니다.

## 생성 후

모든 꼭지점에 grip점이 있으며 어떤 꼭지점을 드래그하든 면적이 실시간으로 재계산됩니다.
