# 결과 보기

현재 도면의 모든 측정 결과를 보고 관리합니다.

## 측정 패널

**측정** 패널을 열면 전체 측정 목록을 볼 수 있습니다. 유형별 필터링을 지원합니다:

- 전체
- 거리
- 각도
- 면적
- 호 길이
- 좌표

각 레코드는 다음을 표시합니다:

- 유형 아이콘
- 측정값(단위 포함)
- 소속 레이아웃

## 선택 및 이동

- 패널의 측정 클릭 → 캔버스가 자동으로 해당 측정 위치로 확대/축소
- 캔버스의 측정 클릭 → 패널에서 해당 항목 강조

## 표시 / 숨기기

- 상태 표시줄의 측정 가시성 버튼으로 모든 측정을 한 번에 표시/숨기기할 수 있습니다
- 숨긴 후에도 측정 데이터는 유지되며 시각적으로만 보이지 않습니다

## 삭제

- 개별 삭제: 선택 후 **Delete** 키
- 전체 삭제: 패널 하단의 "전체 삭제" 버튼
- 삭제는 실행 취소 가능
