# 측정 기능 설명

측정 명령은 도면에서 임시 측정을 수행하는 데 사용됩니다. 모든 측정 결과는 HTML 오버레이로 표시되며, **DWG/DXF 파일에 기록되지 않고** 독립적으로 내보내고 공유할 수 있습니다.

## 측정 생성

명령 선택 후 프롬프트에 따라 필요한 점을 순서대로 클릭합니다. 드래그 중 실시간 미리보기(고무줄 + 측정값 배지)가 제공됩니다.

## 측정 편집

- 측정 객체를 **클릭**하면 선택되며 grip점이 표시됩니다
- **grip점 드래그**로 측정을 조정하며 수치가 실시간으로 갱신됩니다

## 실행 취소 / 다시 실행

측정 작업은 실행 취소와 다시 실행을 지원합니다.

## 단위와 정밀도

측정값의 표시 단위와 정밀도는 설정에서 조정할 수 있으며, 밀리미터 / 센티미터 / 미터 / 피트 / 인치 등을 지원합니다. 이 설정은 원본 DWG/DXF 파일에 영향을 주지 않고 측정 표시에만 영향을 미칩니다.

## 가져오기 / 내보내기

측정 데이터는 JSON sidecar 파일(`도면명.measurement.json`)로 내보낼 수 있어 도면 간, 기기 간 공유에 편리합니다. 가져올 때 모든 측정 객체와 그 스타일이 자동으로 복원됩니다.
