# 각도 측정

세 선으로 구성된 각도를 측정합니다(꼭지점 → 첫 번째 변 → 두 번째 변).

## 상호작용 단계

1. 클릭하여 각도 **꼭지점** 선택
2. 클릭하여 **첫 번째 변 위의 점** 선택
3. 클릭하여 **두 번째 변 위의 점** 선택

## 미리보기

2단계 완료 후 점선 arm1 + 실선 arm2 고무줄 + 각도 배지가 표시됩니다.

## 각도 계산

포함각(내각)을 사용하며 범위는 0° ~ 180°입니다.

## 표시

각도 배지는 각도 이등분선 방향을 따라 꼭지점 위쪽에 위치합니다.

## 생성 후

세 점 모두 grip이 있으며 어떤 것을 드래그하든 각도가 재계산됩니다.
