# 연속 측정

여러 점 사이의 거리를 연속으로 측정하며 각 구간의 길이를 개별적으로 표시합니다.

## 상호작용 단계

1. 첫 번째 점 클릭
2. 이후 점을 순서대로 클릭—클릭할 때마다 새 구간이 즉시 생성되어 길이가 표시
3. **Enter** 또는 **Esc** 키로 종료(또는 시작점/끝점 근처를 클릭하면 자동으로 닫힘)

## 미리보기

완전한 꺾은선 고무줄, 각 구간 중점에 길이 배지.

## 제한

최대 100개 점. 인접한 점 쌍은 실제로 독립적인 거리 측정이며 개별적으로 편집할 수 있습니다.
