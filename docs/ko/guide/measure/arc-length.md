# 호 길이 측정

원호의 길이를 측정합니다. 두 가지 모드를 지원합니다.

## 자동 잠금 모드(권장)

첫 번째 점이 도면에 이미 있는 CIRCLE, ARC 또는 폴리라인 bulge 위에 놓이면 자동으로 잠금 모드로 진입합니다:

- 커서가 원 / 원호 위로 제한
- 원형 snap 표시기 표시
- 마우스 스위프 방향을 따라 자동으로 원호 생성

**Ctrl** 키로 장호 / 단호 방향을 전환할 수 있습니다.

## 3점 자유 모드

첫 번째 점이 어떤 호 위에도 놓이지 않으면 자동으로 3점 모드로 진입합니다:

1. 시작점
2. 통과점
3. 끝점—실시간으로 원호 미리보기

## 표시

원호 Canvas 그리기 + 호 길이 배지.

## 생성 후

끝점 grip을 드래그하여 조정할 수 있습니다.
