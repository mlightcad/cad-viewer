# 사용자 인터페이스

MLightCAD Viewer는 AutoCAD와 유사한 클래식 3단 레이아웃을 사용합니다: 상단 리본, 중앙 캔버스 영역, 하단 상태 표시줄.

## 전체 레이아웃

```
┌───────────────────────────────────────────────┐
│  상단 리본(Ribbon)                             │
├───────────────────────────────────────────────┤
│                                               │
│           캔버스 + 오버레이                    │
│    ┌─────┐                                    │
│    │우측 │  도킹 패널(레이어, 속성 등)          │
│    │도구 │                                    │
│    │모음 │                                    │
│    └─────┘                                    │
│                                               │
├───────────────────────────────────────────────┤
│  상태 표시줄                                  │
└───────────────────────────────────────────────┘
```

## 상단 리본

리본은 탭(Tab)과 그룹(Group) 방식으로 명령 버튼을 구성합니다.

### 파일

| 버튼 | 설명 |
|---|---|
| 열기 | DWG / DXF 파일 열기 |
| DXF 내보내기 | 현재 도면을 DXF 형식으로 내보내기 |
| PNG 내보내기 | 캔버스를 PNG 이미지로 내보내기 |

### 그리기

Line, Circle, Arc, Rect, Polyline, Hatch 등 그리기 명령을 포함합니다. 이 명령들은 검토 모드에서 사용할 수 없습니다.

### 레이어

레이어 켜기/끄기, 동결/해동, 잠금, 격리 등 레이어 작업.

### 수정

Move, Copy, Offset 등 수정 명령.

### 측정

거리, 각도, 면적, 호 길이, 연속 측정, 좌표점. 자세한 내용은 [측정 기능 설명](/ko/guide/measure/overview)을 참조하십시오.

### 주석

화살표, 수정 구름, 사각형, 원, 텍스트, 풍선 주석(Callout), 강조, 도장 등. 자세한 내용은 [주석 기능 설명](/ko/guide/markup/overview)을 참조하십시오.

## 우측 도구 모음

캔버스 우측에 떠 있는 수직 도구 모음으로 자주 사용하는 도구에 빠르게 접근할 수 있습니다:

- **선택**: 엔티티 선택 및 이동
- **이동(팬)**: 드래그하여 뷰 이동
- **전체 확대/축소**: 모든 도형을 중앙에 표시
- **창 확대/축소**: 영역을 지정하여 확대/축소
- **레이어 관리**: 레이어 패널 열기
- **배경 전환**: 밝은/어두운 배경 전환
- **읽기 모드**: 집중해서 읽는 전체 화면 모드 진입
- **측정 도구 그룹**: 측정 도구 패널 팝업
- **주석 도구 그룹**: 주석 도구 패널 팝업(검토 모드에서 표시)

## 도킹 패널

패널은 캔버스 우측에 도킹하거나 플로팅 창으로 드래그할 수 있습니다. 자주 사용하는 패널:

| 패널 | 설명 |
|---|---|
| 레이어 | 모든 레이어를 표시하며 켜기/끄기, 잠금, 동결, 격리 등 작업 지원 |
| 속성 | 선택한 엔티티의 속성 정보 표시 |
| 측정 목록 | 현재 도면의 모든 측정 항목을 표시하며 클릭 시 해당 측정으로 이동 |
| 검토(주석) | 모든 주석을 표시하며 주석 메타데이터 편집, 삭제 등 지원 |
| 통계 | 도면 내 블록 사용 현황 통계 |
| 누락 리소스 | 도면에 누락된 글꼴 또는 외부 참조 표시 |

## 상태 표시줄

상태 표시줄은 인터페이스 하단에 위치하며 왼쪽에서 오른쪽 순서는 다음과 같습니다:

| 영역 | 설명 |
|---|---|
| 레이아웃 탭 | 모델 공간 / 레이아웃 전환 |
| 좌표 | 현재 커서 위치 좌표 표시(데스크톱 전용) |
| OSNAP | 객체 스냅 모드 토글 및 설정 |
| ORTHO | 직교 모드 토글 |
| POLAR | 극축 추적 토글 및 각도 증분 |
| 선두께 표시 | 선두께 굵기 표시 여부 제어 |
| 동적 입력 | 동적 입력 토글 |
| 테마 전환 | 밝은/어두운 테마 |
| 전체 화면 | 전체 화면 모드 |

## 검토 모드

주석 명령을 실행하면 뷰어가 자동으로 **검토 모드**로 진입합니다. 이때 DWG/DXF 배경은 읽기 전용이 되며, 모든 주석과 측정은 오버레이로 표시됩니다. 주석 명령을 종료한 후에도 검토 모드가 유지되며, 수동으로 편집 모드로 전환할 때까지 유지됩니다.

검토 모드에서는 주석 명령이 자동으로 사용 가능하며, 편집 모드에서는 주석 도구를 수동으로 활성화해야 합니다.
