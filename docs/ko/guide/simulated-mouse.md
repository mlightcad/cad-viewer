# 시뮬레이션 마우스（모바일）

터치스크린에서 그릴 때 손가락 자체가 화면의 대상 위치를 가려 잘못된 조작이 발생하기 쉽습니다. 시뮬레이션 마우스는 이 문제를 해결하기 위해 입력점을 손가락 터치 위치에서 손가락 위쪽으로 "올려", 십자 커서로 손가락을 대체하여 정확하게 입력합니다.

<TouchPointAnimation />

## 작동 방식

- **기본적으로 활성화**됩니다.
- 그리기 등의 명령을 실행할 때 손가락으로 화면을 **길게 누르면** 손가락 위쪽에 십자형 시뮬레이션 마우스 커서가 표시됩니다(손가락 위 약 52px 위치).
- 손가락 터치 입력이 **십자 커서 점 입력**으로 변경됩니다: 실제 입력 위치는 십자 커서를 기준으로 하며 손가락이 접촉한 위치가 아니므로 손가락 가림으로 인한 오차를 피할 수 있습니다.

## 켜기 / 끄기

- **설정**에서 시뮬레이션 마우스를 켜거나 끌 수 있습니다.
- 그리기 도중에도 언제든 토글할 수 있습니다.
