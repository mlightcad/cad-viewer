# 세션 패널 (모바일)

데스크톱에서는 커서 근처의 **동적 입력(DYN)** 플로팅 프레임을 통해 사용자가 거리/각도 값을 직접 입력하고 **Enter** 로 확인하거나 **Esc** 로 취소할 수 있습니다. 물리적 키보드가 없는 모바일에서는 이 상호작용 방식을 그대로 가져올 수 없습니다.

**세션 패널**은 모바일판 동적 입력 + 키보드에 해당하는 컴포넌트입니다. 화면 하단에 고정되며 명령 실행 중 자동으로 팝업되어 현재 프롬프트와 실시간 측정값을 표시하고, 화면의 **확인**(✓)과 **취소**(×) 버튼(데스크톱의 **Enter** 와 **Esc** 에 해당)을 제공합니다.

## 패널 구성

확장 모드에서 패널은 위에서 아래로 다음과 같은 영역으로 나뉩니다:

### 세션 액세서리 / 제목 줄

첫 번째 줄의 왼쪽에는 활성 명령이 마운트한 **세션 액세서리** 가 표시됩니다. 명령마다 마운트하는 액세서리가 다릅니다—측정 및 주석 명령은 **도형 스타일 세션 액세서리**(색상 + 글자 높이)를 마운트하고, PLine, Text 등 다른 명령은 자체 전용 액세서리 컨트롤을 마운트할 수 있습니다. 활성 명령이 **세션 액세서리를 전혀 마운트하지 않는 경우**, 첫 번째 줄의 왼쪽에 명령 프롬프트 텍스트가 직접 표시되고(아래 설명할 프롬프트 줄은 나타나지 않습니다).

아래 데모는 도형 스타일 액세서리가 마운트된 측정 / 주석 명령 시나리오입니다:

| 컨트롤 | 아이콘 | 용도 |
|---|---|---|
| 색상 버튼 | <span style="display:inline-block;width:14px;height:14px;border-radius:50%;background:#1a8cff;border:1px solid #555;"></span> | 활성 도형 색상을 설정하는 ACI 색상 팔레트 / 대화상자 열기 |
| 글자 높이 버튼 | <svg xmlns="http://www.w3.org/2000/svg" width="20" height="20" viewBox="0 0 24 24" fill="none" style="vertical-align:middle"><text x="2" y="18" font-family="Georgia, Times New Roman, serif" font-size="16" font-weight="600" fill="#e8eaed">A</text><g stroke="#2dd4bf" stroke-width="1.75" stroke-linecap="round" stroke-linejoin="round" fill="none"><path d="M18 4v16"/><path d="M15.5 6.5 18 4l2.5 2.5"/><path d="M15.5 17.5 18 20l2.5-2.5"/></g></svg> | 글자 크기를 설정하는 글자 높이 대화상자 열기 |

줄의 오른쪽에는 두 개의 원형 아이콘 버튼이 있습니다:

| 버튼 | 아이콘 | 용도 |
|---|---|---|
| 도움말 | ? | 전체 화면 도움말 패널 열기 |
| 접기 / 펼치기 | ▼ / ▲ | 컴팩트 모드와 확장 모드 전환 |

### 프롬프트 줄

두 번째 줄은 **활성 명령이 세션 액세서리를 마운트한 경우에만** 나타납니다. 명령의 **프롬프트 텍스트**(예: "첫 번째 점 지정")와 명령이 선택적 인수를 노출하는 경우 해당 **키워드 칩**(예: `[되돌리기(U)/계속(C)]`)을 표시합니다. 프롬프트는 왼쪽 정렬이며 자동으로 지역화됩니다.

활성 명령이 세션 액세서리를 마운트하지 않은 경우, 프롬프트 텍스트는 첫 번째 줄의 왼쪽(액세서리 위치)으로 직접 이동하며 별도의 두 번째 줄은 표시되지 않습니다.

키워드 칩을 탭하는 것은 데스크톱 명령줄에서 키워드를 입력하는 모바일 버전에 해당합니다.

### 측정값

사용자가 손가락을 드래그할 때 패널은 실시간으로 업데이트됩니다. 표시되는 값은 명령 상태에 따라 다릅니다:

| 상태 | 표시되는 값 | 의미 |
|---|---|---|
| 첫 번째 점을 선택하기 전 | **X** / **Y** | 현재 커서 위치의 절대 좌표 |
| 첫 번째 점을 선택한 후(상대 모드) | **길이** / **각도** | 첫 번째 점에서 현재 위치까지의 거리와 각도 |
| 첫 번째 점을 선택한 후(상대 모드) | **ΔX** / **ΔY** | 첫 번째 점에서 현재 위치까지의 X·Y 방향 델타 |

휴대폰과 패드의 레이아웃은 다릅니다: 휴대폰에서는 각 측정값이 개별 행을 차지하며 취소/확인 버튼이 오른쪽에 내장되고, 패드에서는 측정값이 나란히 배치되며 취소/확인 버튼은 맨 오른쪽 공유 영역에 그룹화됩니다.

### 확인 / 취소 버튼

| 버튼 | 아이콘 | 데스크톱 버전에 해당 | 용도 |
|---|---|---|---|
| **확인** | ✓(파란색 원) | `Enter` / 빈 반환 | 현재 입력을 수락하거나 기본값 사용 |
| **취소** | ×(회색 원) | `Esc` | 현재 명령 중단 |

명령이 빈 반환을 허용하지 않는 경우(사용자가 값을 지정해야 하는 경우) **확인** 버튼은 비활성화됩니다(흐리게 표시).

## 컴팩트 모드

제목 줄의 ▼ 버튼을 탭하여 **컴팩트 모드**로 전환합니다. 패널은 여러 행에서 단일 행으로 축소되며 프롬프트 줄, 측정값, 키워드 칩은 모두 숨겨집니다. 다음만 표시됩니다:

- **세션 액세서리**(마운트된 경우)
- **펼치기** 버튼(▲, 화살표 방향 반전)
- **취소**(×) / **확인**(✓) 버튼

컴팩트 모드는 필수 작업을 유지하면서 명령 실행 중 캔버스를 최대한 넓게 볼 수 있게 합니다. **펼치기** 버튼을 탭하면 확장 모드로 돌아갑니다.

## 휴대폰 vs 패드

세션 패널은 뷰포트 너비에 따라 자동으로 적응합니다:

| 기능 | 휴대폰(≤ 600px) | 패드(> 600px) |
|---|---|---|
| 패널 너비 | 화면 너비 전체 | 중앙 정렬, 고정 480px, 둥근 모서리와 그림자 |
| 측정 레이아웃 | 세로로 쌓이며 측정마다 한 줄 | 나란히 배치되며 두 측정 그룹이 병렬 |
| 버튼 배치 | 취소 / 확인이 서로 다른 측정 행에 내장 | 취소 / 확인이 오른쪽 공유 영역에 그룹화 |
| 컴팩트 스타일 | 너비 전체의 단일 행 | 중앙 정렬된 고정 너비 단일 행 |

## 데스크톱 대응

| 데스크톱 작업 | 모바일 세션 패널 대응 |
|---|---|
| 거리 / 각도를 보여주는 동적 입력(DYN) | 길이, 각도, ΔX, ΔY 를 보여주는 실시간 측정값 |
| 명령줄에서 키워드 옵션 입력 | 키워드 칩 탭 |
| 기본값 수용을 위한 `Enter` / 빈 반환 | **확인**(✓) 버튼 |
| 명령 취소를 위한 `Esc` | **취소**(×) 버튼 |
| 명령줄 프롬프트 `Specify first point:` | 동일한 텍스트를 보여주는 프롬프트 줄 |
