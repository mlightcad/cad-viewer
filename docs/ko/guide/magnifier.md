# 돋보기（모바일）

터치스크린에서 점을 정확하게 선택할 때 손가락이 대상 위치를 가립니다. 돋보기는 시각적 보조를 제공합니다: 화면 왼쪽 상단에 사각형 돋보기 HUD가 표시되어 손가락 터치 지점 부근의 내용을 확대하며, 밀집된 도면에서 작은 객체를 정확하게 선택할 수 있도록 돕습니다.

## 작동 방식

- 길게 누른 후 왼쪽 상단에 사각형 돋보기 HUD가 표시되어 손가락 터치 지점 부근의 내용을 확대합니다.
- 돋보기는 손가락 아래의 정확한 위치를 잘 보이게 합니다.
- 실제 입력 위치는 여전히 손가락 터치 지점을 기준으로 합니다. 돋보기는 시각 보조만 제공하며 입력 위치를 변경하지 않습니다.

## 시뮬레이션 마우스와의 관계

돋보기는 터치 선택의 기본 시각 보조입니다. 시뮬레이션 마우스는 기본적으로 켜져 있으며, 손가락 위의 십자 커서로 돋보기를 대체합니다. **설정**에서 시뮬레이션 마우스를 끄면 길게 누를 때 돋보기 HUD가 표시됩니다:

- **시뮬레이션 마우스 켜짐（기본）**: 손가락 위에 십자 커서가 표시되며, 입력점은 커서 위치로 오프셋됩니다.
- **시뮬레이션 마우스 꺼짐**: 왼쪽 상단에 사각형 돋보기 HUD가 표시되어 손가락 터치 지점 부근의 영역을 확대합니다. 입력 위치는 손가락 터치 지점 그대로입니다.

시뮬레이션 마우스는 스위치 버튼이며, 그리는 도중 언제든 전환할 수 있습니다.
