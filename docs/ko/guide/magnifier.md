# 돋보기（모바일）

터치스크린에서 점을 정확하게 선택할 때 손가락이 대상 위치를 가립니다. 돋보기는 시각적 보조를 제공합니다: 화면 왼쪽 상단에 사각형 돋보기 HUD가 표시되어 입력점 부근의 내용을 확대하며, 밀집된 도면에서 작은 객체를 정확하게 선택할 수 있도록 돕습니다.

<MagnifierAnimation />

## 작동 방식

- 명령이 점 지정을 요구할 때, 화면을 **약 1초간 길게 누르면** 왼쪽 상단에 사각형 돋보기 HUD가 자동으로 표시됩니다.
- 확대되는 영역은 현재 입력점을 따라갑니다. 돋보기는 손가락에 가려지지 않고 입력점 부근의 정확한 위치를 잘 보이게 합니다.
- 돋보기는 시각 보조만 제공하며 입력 위치를 변경하지 않습니다.

## 시뮬레이션 마우스와의 관계

돋보기는 길게 누른 후 항상 표시되며, 시뮬레이션 마우스 켜짐/꺼짐은 돋보기가 **어떤 위치**를 확대하는지에만 영향을 줍니다:

- **시뮬레이션 마우스 켜짐（기본）**: 입력점은 손가락 위 약 52px의 십자 커서 위치로 오프셋되며, 돋보기는 십자 커서 부근의 영역을 확대합니다.
- **시뮬레이션 마우스 꺼짐**: 입력점은 손가락 터치점이 되며, 돋보기는 손가락 터치점 부근의 영역을 확대합니다.

시뮬레이션 마우스는 스위치 버튼이며, **설정**에서 전환하거나 그리는 도중 언제든 전환할 수 있습니다.
