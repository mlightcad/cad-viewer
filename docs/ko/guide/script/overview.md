# 스크립트 기능 설명

스크립트 기능은 도면에서 사용자 정의 JavaScript 코드를 실행하여 조회, 통계, 일괄 편집, 선택 강조 등의 작업을 수행하는 데 사용됩니다. 스크립트는 `cad` 객체를 통해 도면과 상호 작용하며, 외부 모델 연결이나 API Key 설정이 필요하지 않습니다.

스크립트 기능은 `@mlightcad/cad-script-plugin` 플러그인에 의해 제공됩니다. 애플리케이션에서 이 플러그인을 로드한 후에만 스크립트 패널을 사용할 수 있습니다.

## 스크립트 패널 열기

- 명령줄에 `cadscript`를 입력하고 Enter 키를 누릅니다
- 또는 도구 패널에서 「스크립트」 탭을 클릭합니다

스크립트 패널 구성:
- **스크립트 편집기**: JavaScript 함수 본문 작성
- **실행 버튼**: 스크립트 실행(단축키 `Ctrl+Enter`)
- **API 버튼**: API 참조 표시/숨기기
- **결과 영역**: 반환 값, 로그, 오류 메시지 및 엔티티 변경 사항 표시

## 스크립트 실행 방식

스크립트는 엄격 모드에서 실행되며 자동으로 함수로 래핑됩니다:

```javascript
function __cadScript(cad) {
  // 여기에 코드를 작성하세요
}
```

함수의 유일한 매개변수는 `cad`이며, 이를 통해 도면 데이터에 접근하고 작업을 수행합니다.

## 제한 사항

- 스크립트에는 시간 및 단계 수 제한이 있으며, 초과 시 자동으로 중지됩니다
- 페이지 전역 객체(`window`, `document`, `fetch` 등) 접근이 금지됩니다
- `import` / `export` / `this` 등의 구문이 금지됩니다
- 반환 값은 JSON 직렬화 가능한 데이터여야 합니다
- 편집 작업은 `cad.edit.transaction` 내에서 실행되어야 하며, 도면이 편집 가능한 상태여야 합니다

## 초안 저장

편집기 내용은 브라우저 로컬 스토리지에 자동으로 저장되며, 페이지를 새로 고친 후에도 마지막으로 편집한 스크립트가 복원됩니다.
