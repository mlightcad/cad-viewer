# 세션 액세서리

**세션 액세서리**는 특정 시점에 UI에 동적으로 마운트되는 작은 컨트롤 그룹으로, 사용자에게 추가적인 작업 진입점을 제공합니다. 가장 큰 특징은 —— **필요할 때만 나타나고 필요 없어지면 자동으로 사라진다**는 점입니다.

세션 액세서리는 주로 다음 두 가지 상황에서 사용됩니다:

- **모바일 기기**: 모바일에는 데스크톱의 리본 UI가 없어 리본에 있는 많은 명령 옵션을 직접 표시할 수 없습니다. 세션 액세서리는 명령 실행 중이나 객체 선택 시 관련 옵션을 사용자 곁으로 가져옵니다.
- **리본 없는 실행 환경**: 일부 내장형 또는 경량 실행 환경에는 리본 컴포넌트가 없으며, 세션 액세서리는 그런 환경에서도 보조 UI로 사용할 수 있습니다.

세션 액세서리에는 두 종류가 있습니다 —— **명령 세션 액세서리**와 **선택 세션 액세서리**.

## 명령 세션 액세서리

명령 세션 액세서리는 **명령 실행 중에 명령이 마운트**하여 해당 명령 고유의 추가 UI 컨트롤을 제공합니다. 명령이 종료되거나 취소되면 액세서리는 자동으로 숨겨집니다.

대표적인 예는 측정 및 주석 명령이 마운트하는 **도형 스타일 액세서리**입니다 —— 측정하거나 주석을 추가하는 동안 세션 패널의 첫 번째 행에 색상, 글자 높이 버튼이 표시되어 사용자가 명령을 중단하고 리본을 찾지 않고도 그 자리에서 모양을 조정할 수 있습니다.

## 선택 세션 액세서리

선택 세션 액세서리는 **하나 이상의 도형 객체가 선택되었을 때** 나타나며, **바로 가기 도구 모음**의 왼쪽에 부착되고 오른쪽의 빠른 작업 버튼과는 세로 구분선으로 분리됩니다. 선택이 해제되면 선택 세션 액세서리는 자동으로 사라집니다.

선택 세션 액세서리의 역할은 명령 세션 액세서리와 유사합니다 —— 선택된 객체에 대한 상황에 맞는 작업 진입점을 제공하는 것입니다. 예를 들어 주석 텍스트를 선택하면 선택 세션 액세서리에 색상, 글자 높이 조정 컨트롤을 표시할 수 있습니다.

## 두 종류의 세션 액세서리 비교

| 특성 | 명령 세션 액세서리 | 선택 세션 액세서리 |
|---|---|---|
| **표시 시점** | 명령 실행 중 | 하나 이상의 객체를 선택했을 때 |
| **마운트 위치** | 모바일: 세션 패널 첫 번째 행<br/>리본 없는 환경: 명령 UI 영역 | 바로 가기 도구 모음 왼쪽 |
| **숨김 조건** | 명령 종료 또는 취소 | 선택 해제 |
| **대표 컨트롤** | 색상, 글자 높이, 기타 명령 고유 옵션 | 색상, 글자 높이, 객체 속성 편집기 |
| **항상 표시되는가** | 아니오, 명령에 따라 다름 | 아니오, 선택 객체 유형에 따라 다름 |

## 데스크톱 리본과의 관계

데스크톱에서는 명령 관련 옵션이 보통 리본의 "상황별 탭"에 모여 있습니다 —— 어떤 명령이 활성화되면 리본은 자동으로 해당 명령에 대응하는 탭으로 전환됩니다. 세션 액세서리는 본질적으로 **모바일 / 리본 없는 환경에서의 상황별 탭에 대한 경량 대체**입니다:

| 데스크톱 | 모바일 / 리본 없음 |
|---|---|
| 리본 상황별 탭 | 명령 세션 액세서리 (세션 패널 내) |
| 일반 탭의 객체 속성 패널 | 선택 세션 액세서리 (바로 가기 도구 모음 내) |
