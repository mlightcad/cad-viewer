# 쓰기 모드

쓰기 모드는 가장 기능이 완벽한 모드입니다. 리뷰 모드의 모든 기능 외에도, DWG/DXF에서 엔티티를 직접 생성, 편집, 삭제할 수 있어 — 웹 제품이 단순한 읽기 전용 미리보기를 넘어 실제 도면 작업을 처리할 수 있습니다.

파일을 열 때 읽기 전용 또는 리뷰 모드가 명시적으로 지정되지 않은 한, 기본적으로 쓰기 모드가 사용됩니다.

### 상단 Ribbon

Ribbon은 모든 AutoCAD 스타일 탭을 완전히 표시합니다:

| 탭 | 명령 |
|---|---|
| File | 열기, DXF 내보내기, PNG 내보내기, 자체 포함 HTML 내보내기 |
| Draw | 선, 원, 호, 사각형, 폴리라인, 해치, 텍스트, MText, 블록 삽입 등 |
| Modify | 이동, 복사, 오프셋, 트림, 연장, 회전, 스케일, 미러, 어레이 등 |
| Layers | 레이어 관리 (켜기/끄기, 동결/해동, 잠금, 격리, 신규, 삭제) |
| Properties | 색상, 선 유형, 선 두께, 레이어 선택기 |
| Measure | 모든 측정 명령 |
| Markup | 모든 마크업 명령 |

### Command Line

캔버스 하단의 Command Line 창에서 명령 이름을 직접 입력할 수 있습니다 (예: `L` + Enter로 선 그리기, `C` + Enter로 원 그리기). 다음을 지원합니다:
- 명령 프롬프트 및 기록 표시
- 숫자 값 및 좌표 입력
- 위/아래 화살표로 명령 기록 탐색

### 우측 툴바

리뷰 모드 도구 외에, **선택 / 편집 도구 그룹**이 있습니다:

- 선택
- 이동
- 전체 확대
- 창 확대
- 레이어 관리
- 측정 도구 그룹
- 마크업 도구 그룹
- 읽기 모드
- 밝은/어두운 배경 전환

### 도킹 패널

| 패널 | 설명 |
|---|---|
| Layers | 완전한 레이어 관리 |
| Properties | 선택한 엔티티 속성 (유형, 좌표, 레이어, 색상, 선 유형, 선 두께 등), 편집 가능 |
| Measurements | 측정 결과 관리 |
| Review (마크업) | 마크업 관리 |

| Missing Resources | 글꼴 / 외부 참조 경고 |

## 태블릿 (Pad)

태블릿 레이아웃은 데스크톱과 모바일 사이에 있지만, 쓰기 모드는 편집에 필요한 완전한 구성 요소를 유지합니다:

- Ribbon은 완전한 탭을 유지하지만, 명령 버튼은 아이콘으로 축소됩니다
- 우측 툴바는 유지됩니다
- Command Line은 기본적으로 작은 바로 축소됩니다; 클릭 시 확장됩니다
- 도킹 패널은 사이드 서랍으로 확장할 수 있습니다
- 상태 표시줄은 단순화된 형태로 핵심 버튼을 표시합니다

## 모바일

모바일의 쓰기 모드에서, Command Line과 완전한 그리기/수정 기능은 **모바일 명령 오버레이**를 통해 구현되며, 하단 탭 바를 대체합니다.

### 명령 오버레이

그리기 또는 수정 명령을 실행할 때, 화면 하단에 명령 작업 바가 나타나며, 다음을 포함합니다:
- 현재 명령 프롬프트
- ✓ 확인 / ✗ 취소 버튼
- 동적 입력 (DYN) 팝업 패널

### 입력 방법

모바일 그리기는 다음 입력 방법을 사용합니다:
- **탭 점 입력**: 화면을 탭(<0.5초)하여 점 생성
- **드래그 점 입력**: 화면을 길게 누름(>0.5초), 드래그 선택 모드로 진입 후 해제
- **시뮬레이션 마우스**: 기본 활성화; 길게 누르면 손가락 위에 십자선이 나타나며, 실제 입력 위치는 십자선을 기준으로 합니다
- **돋보기**: 설정에서 전환; 원형 돋보기 HUD가 손가락 영역을 확대합니다

### 자동 복귀

명령 실행 중에는 상태 표시줄이 일시적으로 숨겨집니다 (명령 오버레이가 입력을 담당합니다). 명령이 종료되면 상태 표시줄이 복원됩니다.
