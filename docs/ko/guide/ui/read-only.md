# 읽기 전용 모드

읽기 전용 모드는 도면을 순수하게 보고 측정하기 위한 모드입니다. DWG/DXF 배경은 완전히 편집할 수 없으며, 마크업, 그리기, 수정 명령은 모두 사용할 수 없습니다.

읽기 전용 모드에 진입하면 인터페이스는 장치 유형에 따라 자동으로 레이아웃을 조정합니다.

## 데스크톱

### 전체 레이아웃

읽기 전용 모드에는 Ribbon과 상태 표시줄이 없습니다. 인터페이스는 캔버스 중심이며, 모든 명령은 우측 툴바와 도킹 패널을 통해 접근합니다:

### 우측 툴바

캔버스 우측에 떠 있는 수직 툴바 — 읽기 전용 모드의 주요 명령 진입점입니다:

- 선택 / 선택 해제
- 이동 (손)
- 전체 확대
- 창 확대
- 레이어 관리 (패널 열기)
- 측정 도구 그룹 (측정 패널 팝업)
- 읽기 모드 (전체 화면 집중 모드 진입)
- 밝은/어두운 배경 전환

### 도킹 패널

| 패널 | 설명 |
|---|---|
| Layers | 모든 레이어 표시; 켜기/끄기, 잠금, 동결, 격리 지원 |
| Measurements | 현재 도면의 모든 측정 표시; 클릭 시 위치로 이동 |
| Entity Info | 선택한 엔티티의 유형, 좌표, 레이어, 속성 표시 |
| Statistics | 블록 사용 통계 |
| Missing Resources | 누락된 글꼴 또는 외부 참조 경고 |

## 태블릿 (Pad)

태블릿 레이아웃은 데스크톱과 모바일 사이의 컴팩트 디자인입니다:

- 우측 툴바는 유지되지만, 터치를 위해 버튼 간격이 넓어집니다
- 도킹 패널은 기본적으로 아이콘 바로 축소됩니다; 클릭 시 사이드 서랍으로 확장됩니다

## 모바일

모바일은 **하단 탭 바 + 서랍 패널** 디자인을 사용하여, 모든 상호작용을 화면 하단에 집중시키고 상단은 캔버스에 할당합니다.

### 하단 탭 바

화면 하단에 6개의 아이콘 버튼이 표시됩니다:

<MobileBottomTabBar mode="readonly" />

| 버튼 | 기능 |
|---|---|
| Zoom | 확대 도구 그룹: 확대, 축소, 전체 확대, 창 확대 |
| Measure | 측정 도구 그룹: 거리, 연속 거리, 면적, 좌표, 호 길이, 각도 |
| Review | 마크업 진입 (읽기 전용 모드에서는 비활성화, 회색 표시) |
| Layers | 레이어 패널 서랍 열기 |
| Layout | 레이아웃 전환 |
| Setting | 설정 메뉴: 테마, 시뮬레이션 마우스, OSNAP 등 |

### 서랍 패널

Layers 버튼을 탭하면 하단에서 레이어 패널이 팝업되어, 각 레이어의 이름, 가시성(켜기/끄기), 색상 등을 표시합니다. 캔버스나 패널 외부 영역을 탭하면 서랍이 닫힙니다.

### 캔버스 영역

캔버스는 화면 상단을 채웁니다. 측정이 선택되면 캔버스에 측정 배지가 표시됩니다.

### 데스크톱과의 차이점

모바일은 우측 툴바나 도킹 패널을 표시하지 않습니다; 그 기능은 하단 탭 바 + 서랍 패널로 대체됩니다.
