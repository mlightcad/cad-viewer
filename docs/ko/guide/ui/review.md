# 리뷰 모드

리뷰 모드는 읽기 전용 모드 위에 완전한 마크업 기능을 추가합니다. DWG/DXF 배경은 읽기 전용으로 유지되며, 모든 마크업은 HTML 오버레이로 그려지고 사이드카 JSON 파일을 통해 독립적으로 저장/공유됩니다.

리뷰 모드에 진입하면 인터페이스는 자동으로 마크업 관련 도구와 패널을 표시합니다.

## 데스크톱

### 전체 레이아웃

읽기 전용 모드와 동일합니다: Ribbon과 상태 표시줄이 없습니다. 인터페이스는 캔버스 중심이며, 명령은 우측 툴바와 도킹 패널을 통해 접근합니다. 차이점은 우측 툴바에 마크업 도구 그룹이 추가되고, 도킹 패널에 리뷰 패널이 추가된다는 것입니다.

### 우측 툴바

읽기 전용 모드 도구 외에, 화살표, 텍스트, 클라우드, 사각형, 원, Callout, 스탬프 및 기타 마크업 명령을 포함하는 **마크업 도구 그룹** 팝업 패널이 있습니다.

### 도킹 패널

읽기 전용 모드 패널 외에, **Review (마크업) 패널**이 있습니다:

| 패널 | 설명 |
|---|---|
| Review (마크업) | 모든 마크업을 표시하며, 유형별로 아이콘, 작성자, 시간, 요약을 표시합니다. 클릭 시 위치로 이동, 메타데이터 편집(주석 / 상태), 삭제 지원 |

다른 모든 패널(Layers, Measurements, Entity Info, Statistics, Missing Resources)은 읽기 전용 모드와 동일합니다.

## 태블릿 (Pad)

읽기 전용 모드와 동일한 태블릿 레이아웃이지만, 다음이 추가됩니다:

- 우측 툴바에 마크업 도구 그룹 팝업 버튼이 추가됩니다
- 도킹 패널 목록에 "Review" 패널 항목이 추가됩니다

## 모바일

모바일 하단 탭 바의 **Review 버튼**은 이 모드에서 활성화되어 사용 가능합니다.

### 하단 탭 바

| 버튼 | 상태 |
|---|---|
| Zoom | 사용 가능 |
| Measure | 사용 가능 |
| Review | **사용 가능** — 클릭하여 마크업 도구 패널 열기 |
| Layers | 사용 가능 |
| Layout | 사용 가능 |
| Setting | 사용 가능 |

### Review 버튼

Review 버튼을 탭하면 하단에서 마크업 도구 패널이 팝업되어, 화살표, 텍스트, 클라우드, 사각형, 원, Callout, 스탬프 등을 표시합니다. 하나를 선택하면 마크업 명령에 직접 진입하며, 캔버스에 실시간 미리보기와 대화형 생성이 지원됩니다.

### 마크업 목록

Review 패널 하단 또는 보조 보기에서, 현재 도면의 모든 마크업을 볼 수 있습니다. 목록 항목을 클릭하면 다음을 수행할 수 있습니다:

- 캔버스를 마크업 위치로 확대
- 마크업 가시성 전환
- 마크업 메타데이터 편집 열기 (주석 / 상태)

### 마크업 가져오기 / 내보내기

Review 패널 상단에서 내보내기 및 가져오기 버튼을 제공합니다. 사이드카 JSON 파일은 도면과 장치 간에 공유할 수 있습니다.

## 읽기 전용 모드와의 차이점

| 구성 요소 | 읽기 전용 | 리뷰 |
|---|---|---|
| 우측 툴바 · 마크업 도구 그룹 | ✗ | ✓ |
| 도킹 패널 · Review (마크업) | ✗ | ✓ |
| 모바일 · Review 하단 버튼 | 비활성화 (회색) | 사용 가능 |
| 마크업 생성 / 편집 | ✗ | ✓ |
| 마크업 가져오기 / 내보내기 | ✗ | ✓ |
