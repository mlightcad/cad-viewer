# 주석 기능 설명

주석 명령은 도면에 검토 표시를 추가하는 데 사용됩니다. 주석 명령을 실행하면 뷰어가 자동으로 **검토 모드**(DWG/DXF 배경 읽기 전용)로 진입합니다.

모든 주석은 HTML 오버레이로 그려지며, **원본 DWG/DXF 파일을 수정하지 않습니다**. JSON sidecar 파일(`도면명.markup.json`)을 통해 독립적으로 저장 및 공유됩니다.

## 주석 생성

대부분의 주석 명령은 CAD 스타일의 단계별 점 선택 상호작용을 사용합니다:

1. 명령 선택(리본 → 주석 그룹, 또는 우측 도구 모음 주석 팝업 패널)
2. 명령 프롬프트에 따라 필요한 점을 순서대로 클릭
3. 드래그 중 실시간 미리보기(Jig) 제공
4. 완료 후 주석이 캔버스에 즉시 표시

## 주석 편집

- 주석을 **클릭**하면 선택되며 grip 편집점이 표시됩니다
- **grip점 드래그**로 모양, 끝점 등을 조정할 수 있습니다
- 글자가 있는 주석(텍스트, Callout, Callout이 추가된 도형)을 **더블클릭**하면 인라인 글자 편집으로 진입합니다
- 선택 후 **Delete** 키로 삭제

## 실행 취소 / 다시 실행

주석 작업은 실행 취소와 다시 실행을 지원합니다. 실행 취소는 생성 작업뿐만 아니라 grip 편집, 삭제 등의 수정도 취소합니다.

## 가져오기 / 내보내기

- **내보내기**: 현재 모든 주석을 JSON 파일로 내보내기 다운로드
- **가져오기**: 이전에 내보낸 JSON 파일을 불러와 모든 주석 복원

sidecar JSON 파일은 도면 간, 기기 간 공유할 수 있습니다.
