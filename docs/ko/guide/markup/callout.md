# 풍선 주석(Callout)

독립적인 리더선 + 글자 말풍선 조합으로, 멀리서 어떤 디테일을 주석 처리할 때 사용합니다.

## 상호작용 단계

1. 클릭하여 화살표 **tip** 끝 선택(주석 대상 위치를 가리킴)
2. 드래그하여 글자 말풍선 **anchor** 위치 배치—실시간으로 리더선 + 말풍선 미리보기
   - **스마트 마운트**: 첫 번째 점이 기존 수정 구름 / 사각형 / 원형 프레임선 위에 놓이면 해당 도형을 자동으로 재사용하여 리더선과 말풍선만 추가
3. 말풍선에 글자 입력

## 세 개의 grip점

- **tip**: 화살표 끝점, 드래그하여 가리키는 방향 조정
- **anchor**: 말풍선 끝점, 드래그하여 말풍선 위치 조정
- **중점**: tip과 anchor를 동시에 이동, 전체 평행 이동

말풍선 글자를 더블클릭하면 인라인 편집으로 진입할 수 있습니다.
