# 결과 보기

현재 도면의 모든 주석을 보고 관리합니다.

## 주석 패널

**검토** 패널을 열면 전체 주석 목록을 볼 수 있으며, 각 레코드는 다음을 표시합니다:

- 주석 유형(화살표, 수정 구름, 텍스트 등 아이콘)
- 작성자
- 작성 시간
- 선택 사항: 주석 글자 내용 요약

## 선택 및 이동

- 패널의 주석 클릭 → 캔버스가 자동으로 **포커스**(해당 주석 위치로 확대/축소)
- 캔버스의 주석 클릭 → 패널에서 해당 항목 강조

## 메타데이터 편집

일부 주석은 패널에서 **Comment**(비고)와 **Status**(상태, 예: Open / Resolved) 등 메타데이터를 편집할 수 있습니다.

## 표시 / 숨기기

- 패널에서 개별 주석의 가시성을 토글할 수 있습니다
- 상태 표시줄의 주석 가시성 버튼으로 모든 주석을 한 번에 표시/숨기기할 수 있습니다

## 삭제

- 개별 삭제: 선택 후 **Delete** 키
- 전체 삭제: 패널에서 "전체 삭제" 클릭
- 삭제는 실행 취소 가능

## 가져오기 / 내보내기

패널 상단에 내보내기 및 가져오기 버튼이 제공되며, sidecar JSON 파일은 도면 간, 기기 간 공유할 수 있습니다.
