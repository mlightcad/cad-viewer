# PDF 도면 변환

PDF 도면에는 인쇄된 모양만 남아 있습니다. 곡선은 베지어 경로가 되고, 문자는 획으로 바뀌는 경우가 많으며, 치수와 블록은 흩어진 선이 됩니다. 리본 **AI** 탭의 **PDF** 패널로 이런 도면을 편집할 수 있는 CAD 객체로 되돌릴 수 있습니다. 확실한 부분은 가져올 때 자동으로 변환되고, 나머지는 예시를 고르거나 찾은 결과를 확인해 변환합니다.

| 버튼 | 명령 | 기능 |
|---|---|---|
| PDF 가져오기 | `pdfimport` / `-pdfimport` | PDF 한 페이지를 가져오고 곡선, 블록, 선 가중치, 선종류를 복원 |
| 축척 보정 | `pdfscale` | 알려진 거리 하나로 실제 크기에 맞게 축척 조정 |
| 문자 인식 | `pdftext` | 분해된 문자 획을 문자로 되돌림 |
| 블록 만들기 | `pdfblock` | 반복되는 형상을 블록으로 되돌림 |
| 치수 인식 | `pdfdim` | 분해된 치수를 치수 객체로 되돌림 |

이 명령들은 **쓰기** 모드가 필요합니다. 권장 순서: `pdfimport` → `pdfscale` → `pdftext` → `pdfblock` → `pdfdim`.

## 가져오기 (`pdfimport`)

1. PDF 파일을 선택하면 [PDF 가져오기] 대화상자가 열립니다.
2. [가져올 페이지]에서 페이지를 고릅니다(여러 페이지 파일만). 미리보기에 해당 페이지가 표시되고, 옆의 축소판 버튼으로 모든 페이지를 볼 수 있습니다. [찾아보기...]로 다른 파일을 고를 수 있습니다.
3. [위치]에서 삽입점 X/Y(기본값은 원점)를 입력하거나, [화면상에 삽입점 지정]을 선택해 확인 후 도면에서 지정합니다. [축척]은 가져올 때 적용할 균일 배율입니다.
4. [가져오기 모드]에서 가져오기 방식을 고릅니다:
   - **도면 복원**(기본값): 원본 도면을 최대한 복원합니다(아래 참조).
   - **PDF 모양 유지**: PDF의 모양을 그대로 유지합니다. 모든 경로는 선 또는 폴리선(곡선은 분할)이 되고 텍스트 런은 각각 문자가 되며, 병합·중복 제거·블록화를 하지 않습니다. 복원으로 모양이 달라질 때 사용합니다.
5. [확인]을 클릭합니다. 위치, 축척, 모드는 다음 `pdfimport`를 위해 기억됩니다.

`-pdfimport`는 대화상자 없이 가져옵니다. 파일을 고른 뒤 명령행에서 페이지 번호(여러 페이지 파일만)와 [축척]·[모드] 옵션이 있는 삽입점을 묻습니다. Enter를 누르면 원점에 놓입니다.

**도면 복원** 모드에서 자동으로 복원되는 것:

- **곡선**: 베지어 원, 호, 타원은 원, 호, 타원이 되고, 선과 호가 섞인 외곽선은 호 구간이 있는 폴리선이 됩니다. 이미 짧은 선으로 나뉜 호는 다시 맞추고, 자유 곡선은 스플라인이 됩니다.
- **블록**: 같은 PDF 폼으로 여러 번 그려진 내용은 하나의 블록(`PDF_FORM_n`)이 되고, 회전되거나 대칭된 것을 포함해 각 위치가 블록 참조가 됩니다.
- **스타일**: 선 너비는 선 가중치로, 점선은 `PDF_DASH_*` 선종류로, 문자는 `PDF_<글꼴>` 문자 스타일로 바뀝니다. 한 줄이 쪼개진 문자는 합쳐집니다.
- **정리**: 완전히 겹치는 중복 외곽선은 제거됩니다.

채워진 영역(색상 패널, 채워진 로고와 문자 윤곽)은 채우기 색의 솔리드 해치로, 페이지와 같은 그리기 순서로 가져옵니다. 통합하는 쪽에서는 `fillHatches` 옵션을 `false`로 설정해 외곽선만 가져올 수 있습니다.

패턴 해치(ANSI31, 벽돌, 교차 해치 등)는 PDF에서 수천 개의 짧은 선으로 저장됩니다. **도면 복원** 모드에서는 이 선들을 표준 `acadiso.pat` 패턴(또는 사용자 정의 단일·이중 패턴)과 대조해, 그려질 때의 축척·각도·원점과 함께 해치 객체로 다시 만듭니다. 경계는 그려진 닫힌 윤곽, PDF 클립 경로 또는 선의 끝점에서 구합니다. 다시 그린 해치가 페이지의 선과 일치할 때만 해치로 만들고, 그렇지 않으면 선으로 남겨 둡니다. 통합하는 쪽에서는 `recognizeHatches`를 `false`로 설정해 모든 선을 그대로 유지할 수 있습니다.

두 모드 모두 뷰어가 보통 PDF와 다른 글꼴로 그리기 때문에, 문자는 PDF에서의 폭에 맞게 늘이거나 줄입니다. 그림(사진, 로고, QR 코드)은 `PDF_IMAGE_n.png`라는 이름의 래스터 이미지로 가져옵니다. DWG와 DXF는 이미지를 외부 파일로 참조하므로 픽셀은 열려 있는 도면 안에만 유지됩니다. QR 코드처럼 투명 배경의 검은 그림은 PDF 페이지와 같이 흰 바탕 위에 놓입니다.

## 축척 보정 (`pdfscale`)

PDF는 보통 1:50, 1:100 같은 축척으로 인쇄됩니다.

1. 축척을 바꿀 객체를 선택합니다.
2. 길이를 아는 거리(치수가 있는 모서리 등)의 양 끝을 지정합니다.
3. 실제 길이를 입력합니다.

선택에 분해된 치수가 있으면 치수 문자에서 추정한 축척으로 실제 길이가 미리 채워집니다. Enter로 확정하면 됩니다.

## 문자 인식 (`pdftext`)

1. 문자가 있는 영역을 선택합니다. 테두리 등 큰 선은 무시됩니다.
2. 스트로크가 문자 행으로 묶이고, 각 행이 **SHX** 문자(열린 선 스트로크)인지 **TrueType** 문자(닫힌 윤곽선)인지 판별됩니다. 이전에 입력한 글자 모양으로만 이루어진 행은 바로 읽힙니다.
3. 이미지를 지원하는 AI 모델이 설정되어 있으면(`LLMSETTINGS`) 나머지 모든 행이 적은 수의 요청으로 한 번에 전송됩니다. 인식에 실패하면 이유(예: 잘못된 API 키)가 표시됩니다.
4. 팔레트에 **문자 인식** 패널이 열리고 도면에 변환 결과 미리보기가 표시됩니다. 패널이 열려 있는 동안 화면 이동과 줌을 할 수 있습니다.
   - SHX 문자와 TrueType 문자 각각에 대해 기존 **문자 스타일**을 선택하거나 새로 만들고, 사용하는 **글꼴**과 **큰 글꼴**을 확인합니다. 원본과 맞지 않으면 바꿉니다. 글꼴이 없으면 대신 표시되는 글꼴이, 기존 스타일의 글꼴을 바꾸면 그 스타일을 쓰는 기존 문자도 바뀐다는 경고가 표시됩니다. 기본적으로 SHX 문자는 `PDF_SHX` 스타일(`txt` + `gbcbig`)을 사용하여 SHX 문자의 모양과 크기를 유지합니다.
   - **높이 축척**을 조정하고, **폭 비율**은 원래 폭에 맞추거나 직접 설정합니다.
   - 목록에는 각 행의 문자와 출처(학습됨, OCR, 편집됨, 인식 안 됨)가 표시되며, 읽지 못한 행이 맨 앞에 옵니다. 행을 클릭하면 도면에서 해당 행이 표시됩니다. 문자를 고치거나 입력하고 Enter 키를 누르면 다음 인식 안 된 행으로 이동합니다. 한 행을 입력하면 같은 글자 모양을 쓰는 다른 행도 자동으로 채워집니다. 체크를 해제하면 그 행을 건너뛰고, 잘못 판별된 행은 SHX와 TrueType 간에 전환할 수 있습니다.
   - 하나의 문자열인데 여러 행으로 인식된 문자는 하나의 여러 줄 문자(MTEXT)로 결합할 수 있습니다. Ctrl+클릭 또는 Shift+클릭으로 행을 선택한 후 **여러 줄 문자로 결합**을 클릭하거나, **인접 문자 결합**을 클릭하여 같은 기준선에서 서로 인접한 것을 모두 결합합니다. 기준선이 다른 행은 원래 줄 간격을 유지한 채 여러 줄 문자의 별도 줄이 됩니다. **분할**을 클릭하면 결합한 문자를 원래 행으로 되돌립니다.
   - **원래 선 숨기기**를 선택하면 미리보기만 볼 수 있습니다.
5. **적용**을 클릭하면 변환됩니다. **취소**하거나 팔레트를 닫으면 아무것도 바뀌지 않습니다.

입력한 글자 모양은 모두 브라우저에 기억되므로 같은 글꼴을 쓰는 다른 도면에도 도움이 됩니다. AI 모델이 인식한 문자는 기억되지 않습니다. 명령 전체를 한 번에 명령 취소할 수 있으며, 변환된 문자는 다른 문자처럼 편집할 수 있습니다.

## 블록 만들기 (`pdfblock`)

1. 반복되는 기호 중 **하나**의 객체를 선택합니다.
2. 블록 기준점을 지정합니다. **축척** 옵션을 켜면 크기가 다른 사본도 일치 대상이 됩니다.
3. 블록 이름을 확인합니다.
4. 회전되거나 대칭된 것을 포함한 다른 사본이 모두 강조 표시됩니다. **예**는 모두 바꾸고, **아니요**는 선택한 것만 블록으로 만들며, **개별 확인**은 사본마다 정합니다.

## 치수 인식 (`pdfdim`)

1. 치수가 있는 영역을 선택합니다.
2. 다음 치수를 인식합니다.
   - **선형 치수**: 모든 각도, 안쪽 또는 바깥쪽 화살표, 건축용 사선 끝, 연속 치수.
   - **반지름·지름 치수**: 원에 닿는 화살표와 `R…` 또는 `Ø…` 문자.
   - **각도 치수**: 양 끝에 화살표가 있는 호.
3. 블록과 마찬가지로 **예**, **아니요**, **개별 확인** 중에서 고릅니다.

치수는 문자 높이와 화살표 크기가 PDF와 같은 `PDF_DIM` 스타일을 사용합니다. 선형 축척 비율은 치수 문자에서 읽은 도면 축척으로 설정되므로 1:100 도면도 실제 값이 표시됩니다. 측정값과 다르거나 기호가 붙은 문자는 그대로 유지됩니다.

::: tip
형상을 실제 크기로 만들려면 먼저 `pdfscale`을 실행하세요. 그러면 `pdfdim`에서 축척이 1:1이 됩니다.
:::
