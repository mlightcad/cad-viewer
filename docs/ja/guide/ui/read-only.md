# 読み取り専用モード

読み取り専用モードは、図面の閲覧と計測のみを行うためのモードです。DWG/DXF の背景は完全に編集不可となり、マークアップ、作図、変更の各コマンドはすべて使用できません。

読み取り専用モードに入ると、インターフェースはデバイスの種類に応じてレイアウトを自動的に調整します。

## デスクトップ

### 全体レイアウト

読み取り専用モードには Ribbon もステータスバーもありません。インターフェースはキャンバス中心で、すべてのコマンドは右側のツールバーとドックパネルからアクセスします。

```
┌──────────────────────────────────────────────────────┐
│                                                      │
│                                                      │
│                  Canvas + Overlays                   │
│                                                      │
│    ┌────┐                                            │
│    │ R  │   Docked Panels (Layers, Measurements,     │
│    │ T  │   Entity Info, etc.)                       │
│    │ B  │                                            │
│    └────┘                                            │
│                                                      │
└──────────────────────────────────────────────────────┘
```

### 右側のツールバー

キャンバスの右側に浮遊する垂直ツールバー — 読み取り専用モードにおける主要なコマンドのエントリーポイントです。

- 選択 / 選択解除
- パン (手のアイコン)
- 全体にズーム
- ウィンドウズーム
- レイヤー管理 (パネルを開く)
- 計測ツールグループ (計測パネルをポップアップ)
- 閲覧モード (フルスクリーンの集中モードに入る)
- 背景の明/暗の切り替え

### ドックパネル

| パネル | 説明 |
|---|---|
| Layers | すべてのレイヤーをリスト表示。オン/オフ、ロック、フリーズ、アイソレートをサポート |
| Measurements | 現在の図面内のすべての計測をリスト表示。クリックで位置を表示 |
| Entity Info | 選択したエンティティのタイプ、座標、レイヤー、プロパティを表示 |
| Statistics | ブロック使用統計 |
| Missing Resources | 欠落しているフォントや外部参照の警告 |

## タブレット (Pad)

タブレットのレイアウトは、デスクトップとモバイルの中間に位置するコンパクトな設計です。

- 右側のツールバーは維持されますが、タッチ操作のためボタンの間隔が広くなります
- ドックパネルはデフォルトでアイコンバーに折りたたまれており、クリックするとサイドドロワーとして展開します

## モバイル

モバイルは **下部タブバー + ドロワーパネル** の設計を採用し、すべてのインタラクションを画面下部に集約し、上部はキャンバス用に残します。

### 下部タブバー

画面の下部に 6 つのアイコンボタンが表示されます。

```
┌──────┬─────────┬────────┬────────┬────────┬─────────┐
│ Zoom │ Measure │ Review │ Layers │ Layout │ Setting │
└──────┴─────────┴────────┴────────┴────────┴─────────┘
```

| ボタン | 機能 |
|---|---|
| Zoom | ズームツールグループ: 拡大、縮小、全体にズーム、ウィンドウズーム |
| Measure | 計測ツールグループ: 距離、連続距離、面積、座標、円弧長、角度 |
| Review | マークアップエントリー (読み取り専用モードでは無効化され、グレーアウト) |
| Layers | レイヤーパネルドロワーを開く |
| Layout | レイアウトの切り替え |
| Setting | 設定メニュー: テーマ、模擬マウス、OSNAP など |

### ドロワーパネル

Layers ボタンをタップすると、下部からレイヤーパネルがポップアップし、各レイヤーの名前、可視性 (オン/オフ)、色などが表示されます。キャンバスまたはパネル外の領域をタップすると、ドロワーが閉じます。

### キャンバス領域

キャンバスは画面の上部を占めます。計測が選択されると、キャンバス上に計測バッジが表示されます。

### デスクトップとの違い

モバイルでは右側のツールバーやドックパネルは表示されず、それらの機能は下部タブバー + ドロワーパネルに置き換えられます。
