# レビューモード

レビューモードは、読み取り専用モードの上に完全なマークアップ機能を追加したものです。DWG/DXF の背景は読み取り専用のままですが、すべてのマークアップは HTML オーバーレイとして描画され、サイドカー JSON ファイルを介して独立して保存/共有されます。

レビューモードに入ると、インターフェースには自動的にマークアップ関連のツールとパネルが表示されます。

## デスクトップ

### 全体レイアウト

読み取り専用モードと同じく、Ribbon もステータスバーもありません。インターフェースはキャンバス中心で、コマンドは右側のツールバーとドックパネルからアクセスします。異なる点は、右側のツールバーにマークアップツールグループが追加され、ドックパネルにレビューパネルが追加されることです。

### 右側のツールバー

読み取り専用モードのツールに加え、**マークアップツールグループ** のポップアップパネルがあり、矢印、テキスト、雲形、長方形、円、Callout、スタンプなどのマークアップコマンドが含まれます。

### ドックパネル

読み取り専用モードのパネルに加え、**レビュー (マークアップ) パネル** があります。

| パネル | 説明 |
|---|---|
| Review (Markup) | すべてのマークアップをリスト表示し、タイプごとにアイコン、作成者、時刻、サマリーを表示。クリックで位置表示、メタデータ編集 (コメント / ステータス)、クリアをサポート |

その他のすべてのパネル (Layers、Measurements、Entity Info、Statistics、Missing Resources) は読み取り専用モードと同じです。

## タブレット (Pad)

読み取り専用モードと同じタブレットレイアウトですが、以下の点が異なります。

- 右側のツールバーにマークアップツールグループのポップアップボタンが追加されます
- ドックパネルのリストに「Review」パネルのエントリーが追加されます

## モバイル

モバイルの下部タブバーにある **Review ボタン** は、このモードではアクティブで利用可能です。

### 下部タブバー

| ボタン | ステータス |
|---|---|
| Zoom | 利用可能 |
| Measure | 利用可能 |
| Review | **利用可能** — クリックするとマークアップツールパネルを開く |
| Layers | 利用可能 |
| Layout | 利用可能 |
| Setting | 利用可能 |

### Review ボタン

Review ボタンをタップすると、下部からマークアップツールパネルがポップアップし、矢印、テキスト、雲形、長方形、円、Callout、スタンプなどがリスト表示されます。いずれかを選択するとマークアップコマンドに直接入り、キャンバス上でリアルタイムプレビューとインタラクティブな作成が行えます。

### マークアップリスト

Review パネルの下部、またはセカンダリビューで、現在の図面上のすべてのマークアップを確認できます。リスト項目をクリックすると、以下の操作が可能です。

- キャンバスをマークアップの位置にズーム
- マークアップの可視性を切り替え
- マークアップのメタデータ編集 (コメント / ステータス) を開く

### マークアップのインポート / エクスポート

Review パネルの上部にはエクスポートボタンとインポートボタンがあります。サイドカー JSON ファイルは、図面やデバイス間で共有できます。

## 読み取り専用モードとの違い

| コンポーネント | 読み取り専用 | レビュー |
|---|---|---|
| 右側ツールバー · マークアップツールグループ | ✗ | ✓ |
| ドックパネル · Review (Markup) | ✗ | ✓ |
| モバイル · Review 下部ボタン | 無効化 (グレーアウト) | 利用可能 |
| マークアップの作成 / 編集 | ✗ | ✓ |
| マークアップのインポート / エクスポート | ✗ | ✓ |
