# スクリプト機能の説明

スクリプト機能は、図面上でカスタム JavaScript コードを実行し、クエリ、統計、一括編集、選択ハイライトなどの操作を行うためのものです。スクリプトは `cad` オブジェクトを通じて図面と対話し、外部モデルへの接続や API Key の設定は不要です。

スクリプト機能は `@mlightcad/cad-script-plugin` プラグインによって提供されます。このプラグインをアプリケーションにロードした後でのみ、スクリプトパネルを使用できます。

## スクリプトパネルを開く

- コマンドラインで `cadscript` と入力して Enter を押す
- またはツールパネルの「スクリプト」タブをクリック

スクリプトパネルの構成：

- **スクリプトエディタ**：JavaScript の関数本体を記述
- **実行ボタン**：スクリプトを実行（ショートカット `Ctrl+Enter`）
- **ヘルプ**：現在の言語でこの説明を開きます
- **例**：説明文で組み込みスクリプトを検索し、エディターに読み込みます
- **結果エリア**：戻り値を折りたたみ可能な JSON ツリーで表示し、ログ、エラー、エンティティの変化も表示します。エディタとの間の分割線をドラッグして高さを調整できます。

## スクリプトの実行方式

スクリプトは strict モードで実行され、自動的に関数でラップされます：

```javascript
function __cadScript(cad) {
  // 你的代码写在这里
}
```

関数の唯一の引数は `cad` で、これを通じて図面データへのアクセスや操作を実行します。

## 制限

- スクリプトには実行時間とステップ数の制限があり、超過すると自動的に停止されます
- ページのグローバルオブジェクト（`window`、`document`、`fetch` など）へのアクセスは禁止
- `import` / `export` / `this` などの構文は禁止
- 戻り値は JSON シリアライズ可能なデータである必要があります
- 編集操作は `cad.edit.transaction` 内で実行する必要があり、図面が編集可能な状態である必要があります

## 下書きの保存

エディタの内容はブラウザのローカルストレージに自動保存され、ページを更新しても前回編集したスクリプトが復元されます。
