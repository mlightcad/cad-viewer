# 拡大鏡（モバイル）

タッチスクリーンでポイントを正確に拾う際、指が対象位置を隠してしまいます。拡大鏡は視覚的補助を提供します：画面左上に四角形の拡大鏡 HUD が表示され、指のタッチ点付近の内容を拡大表示し、密集した図面で小さなオブジェクトを正確に選択できるように支援します。

## 動作方式

- 長押し後、左上に四角形の拡大鏡 HUD が表示され、指のタッチ点付近の内容を拡大表示します。
- 拡大鏡は指の下の正確な位置を見やすくします。
- 実際の入力位置は引き続き指のタッチ点基準となります。拡大鏡は視覚補助のみを提供し、入力位置を変更しません。

## 擬似マウスとの関係

拡大鏡はタッチ拾取の基本視覚補助です。擬似マウスはデフォルトでオンであり、指の上の十字カーソルで拡大鏡を代替します。**設定**で擬似マウスをオフにすると、長押し時の表示が拡大鏡 HUD に切り替わります：

- **擬似マウスオン（デフォルト）**：指の上に十字カーソルが表示され、入力点はカーソル位置にオフセットされます。
- **擬似マウスオフ**：左上に四角形の拡大鏡 HUD が表示され、指のタッチ点付近の領域を拡大表示します。入力位置は指のタッチ点のままです。

擬似マウスはスイッチボタンで、作図中もいつでも切替可能です。
