# 引出注釈（Callout）

独立した引出線 + 文字バブルの組み合わせで、離れた位置からある詳細を注釈する際に使用します。

## 操作手順

1. クリックして矢印 **tip** 端を選択（注釈対象の位置を指す）
2. ドラッグして文字バブルの **anchor** 位置を配置——引出線 + バブルをリアルタイムプレビュー
   - **スマートマウント**：最初の点が既存の修正クラウド / 長方形 / 円形の枠線上にある場合、その形状を自動的に再利用し、引出線とバブルだけを追加
3. バブルに文字を入力

## 3 つの grip 点

- **tip**：矢印の端点。ドラッグで指向きを調整
- **anchor**：バブルの端点。ドラッグでバブル位置を調整
- **中点**：tip と anchor を同時に移動し、全体を平行移動

バブルの文字をダブルクリックするとインライン編集に入ります。
