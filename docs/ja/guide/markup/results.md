# 結果を確認

現在の図面内のすべての注釈を確認・管理します。

## 注釈パネル

**レビュー**パネルを開くと完全な注釈リストが表示され、各レコードには以下が表示されます：

- 注釈タイプ（矢印、修正クラウド、テキストなどのアイコン）
- 作成者
- 作成日時
- オプション：注釈文字内容の要約

## 選択と位置合わせ

- パネル内の注釈をクリック → キャンバスが自動的に **focus**（その注釈の位置までズーム）
- キャンバス内の注釈をクリック → パネル内の該当項目をハイライト

## メタデータの編集

一部の注釈はパネルで **Comment**（コメント）や **Status**（ステータス、Open / Resolved など）などのメタデータを編集できます。

## 表示 / 非表示

- パネルで個々の注釈の表示/非表示を切替可能
- ステータスバーの注釈可視性ボタンで全注釈を一括表示/非表示可能

## クリア

- 個別クリア：選択後 **Delete** を押す
- 全クリア：パネルの「すべてクリア」をクリック
- クリア操作は元に戻せます

## インポート / 書き出し

パネル上部に書き出し・インポートボタンがあり、サイドカー JSON ファイルは図面をまたいだ、デバイスをまたいだ共有が可能です。
