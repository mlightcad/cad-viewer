# PDF 図面の変換

PDF 図面には印刷された形しか残っていません。曲線はベジェパスになり、文字はストロークになっていることが多く、寸法やブロックはばらばらの線になっています。リボンの **AI** タブにある **PDF** パネルで、こうした図面を編集できる CAD オブジェクトに戻せます。確実に判断できるものは読み込み時に自動で変換され、それ以外は見本を選ぶか、見つかった結果を確認して変換します。

| ボタン | コマンド | 内容 |
|---|---|---|
| PDF 読み込み | `pdfimport` / `-pdfimport` | PDF の 1 ページを読み込み、曲線・ブロック・線の太さ・線種を復元 |
| 尺度校正 | `pdfscale` | 既知の距離 1 か所から実寸に尺度変更 |
| 文字認識 | `pdftext` | 分解された文字のストロークを文字に戻す |
| ブロック作成 | `pdfblock` | 繰り返し出てくる図形をブロックに戻す |
| 寸法認識 | `pdfdim` | 分解された寸法を寸法オブジェクトに戻す |

これらのコマンドには**書き込み**モードが必要です。おすすめの順序：`pdfimport` → `pdfscale` → `pdftext` → `pdfblock` → `pdfdim`。

## 読み込み（`pdfimport`）

1. PDF ファイルを選ぶと、［PDF 読み込み］ダイアログが開きます。
2. ［読み込むページ］でページを選びます（複数ページのファイルのみ）。プレビューにそのページが表示され、横のサムネイル ボタンで全ページを一覧できます。［参照...］で別のファイルを選べます。
3. ［位置］で挿入点の X/Y（既定は原点）を入力するか、［挿入位置を画面上で指定］をオンにして OK の後に図面上で指定します。［尺度］は読み込み時の一律の倍率です。
4. ［読み込みモード］で読み込み方式を選びます：
   - **図面を復元**（既定）：元の図面をできるだけ復元します（下記参照）。
   - **PDF の見た目を保持**：PDF の見た目をそのまま保持します。各パスは線分またはポリライン（曲線は分割）に、各テキストランはそれぞれ文字になり、結合・重複除去・ブロック化は行いません。復元で見た目が変わる場合に使います。
5. ［OK］をクリックします。位置・尺度・モードは次の `pdfimport` のために記憶されます。

`-pdfimport` はダイアログを表示せずに読み込みます。ファイル選択後、コマンド ラインでページ番号（複数ページのファイルのみ）と、［尺度］［モード］オプション付きの挿入点を尋ねます。Enter で原点に配置されます。

**図面を復元**モードで自動的に復元されるもの：

- **曲線**：ベジェの円・円弧・楕円は円・円弧・楕円に、線と円弧が混ざった輪郭は円弧セグメント付きのポリラインになります。短い線に分割済みの円弧は当てはめ直され、自由曲線はスプラインになります。
- **ブロック**：同じ PDF フォームで何度も描かれた内容は 1 つのブロック（`PDF_FORM_n`）になり、回転・鏡像のものも含めて各所がブロック参照になります。
- **スタイル**：線幅は線の太さに、破線は `PDF_DASH_*` 線種に、文字は `PDF_<フォント>` 文字スタイルになります。1 行が分割された文字はつなげられます。
- **整理**：完全に重なった重複輪郭は取り除かれます。

塗りつぶし領域（色付きの帯、塗りつぶされたロゴや文字の輪郭）は、塗りの色のソリッドハッチングとしてページと同じ描画順で読み込まれます。組み込み側は `fillHatches` オプションを `false` にすると輪郭だけを読み込めます。

パターンハッチング（ANSI31、レンガ、クロスハッチなど）は、PDF では数千本の短い線分になっています。**図面を復元**モードでは、これらの線分を標準の `acadiso.pat` パターン（またはユーザー定義の単一・二方向パターン）と照合し、描かれたときの尺度・角度・原点とともにハッチング オブジェクトとして再構築します。境界は、描かれた閉じた輪郭、PDF のクリップパス、または線分の端点から求めます。再描画したハッチングがページ上の線分と一致する場合にのみハッチングにし、それ以外は線分のまま残します。組み込み側は `recognizeHatches` を `false` にすると、すべての線分をそのまま残せます。

どちらのモードでも、ビューアーは通常 PDF とは別のフォントで描くため、文字は PDF 上の幅に合わせて伸縮されます。画像（写真、ロゴ、QR コード）は `PDF_IMAGE_n.png` という名前のラスターイメージとして読み込まれます。DWG と DXF は画像を外部ファイルとして参照するため、ピクセルは開いている図面の中にだけ保持されます。QR コードのような透明背景の黒い画像は、PDF ページと同じく白地の上に置かれます。

## 尺度校正（`pdfscale`）

PDF は通常 1:50 や 1:100 などの尺度で印刷されています。

1. 尺度変更するオブジェクトを選択します。
2. 長さがわかっている距離（寸法の入った辺など）の両端を指定します。
3. 実際の長さを入力します。

選択に分解された寸法が含まれていれば、寸法値から推定した尺度で実際の長さがあらかじめ入力されます。Enter で確定できます。

## 文字認識（`pdftext`）

1. 文字がある範囲を選択します。枠などの大きな線は無視されます。
2. ストロークは文字行にまとめられ、各行が **SHX** 文字（開いた線のストローク）か **TrueType** 文字（閉じたアウトライン）かが判定されます。以前に入力した字形だけでできた行はすぐに読み取られます。
3. 画像に対応した AI モデルが設定されている場合（`LLMSETTINGS`）、残りの行はまとめて少ない回数のリクエストで送信されます。認識に失敗した場合は、理由（例：API キーが無効）が表示されます。
4. パレットに**文字認識**パネルが開き、図面に変換結果のプレビューが表示されます。パネルを開いたまま画面移動やズームができます。
   - SHX 文字と TrueType 文字それぞれについて、既存の**文字スタイル**を選ぶか新しく作成し、使用する**フォント**と**ビッグフォント**を確認します。元の図面と合わない場合は置き換えます。フォントが見つからない場合は代わりに表示されるフォントが、既存スタイルのフォントを変更する場合はそのスタイルを使う既存の文字も変わることが表示されます。既定では SHX 文字は `PDF_SHX` スタイル（`txt` + `gbcbig`）を使い、SHX 文字の見た目と大きさを保ちます。
   - **高さの尺度**を調整し、**幅係数**は元の幅に合わせるか手動で設定します。
   - 一覧には各行の文字とその出所（学習済み、OCR、編集済み、未認識）が表示され、読み取れなかった行が先頭に並びます。行をクリックすると図面でその行が表示されます。文字を修正または入力して Enter キーを押すと次の未認識の行に移ります。1 行入力すると、同じ字形を使う他の行も自動的に埋まります。チェックを外すとその行はスキップされ、判定を誤った行は SHX と TrueType を切り替えられます。
   - 1 つの文字列なのに別々の行として認識された文字は、1 つのマルチテキスト（MTEXT）に結合できます。Ctrl+クリックまたは Shift+クリックで行を選択して**マルチテキストに結合**をクリックするか、**隣接文字を結合**をクリックして同じベースライン上で隣り合うものをまとめて結合します。異なるベースラインの行は、元の行間隔を保ったままマルチテキスト内の別の行になります。**分割**で結合した文字を元の行に戻せます。
   - **元の線分を非表示**にするとプレビューだけを確認できます。
5. **適用**をクリックすると変換されます。**キャンセル**またはパレットを閉じると何も変更されません。

入力した字形はすべてブラウザーに記憶されるため、同じフォントを使う他の図面にも役立ちます。AI モデルが読み取った文字は記憶されません。コマンド全体は 1 回で元に戻すことができ、変換された文字は通常の文字と同じように編集できます。

## ブロック作成（`pdfblock`）

1. 繰り返し出てくる記号のうち**1 つ**のオブジェクトを選択します。
2. ブロックの基点を指定します。**尺度**オプションで大きさの違うコピーも一致の対象になります。
3. ブロック名を確認します。
4. 回転・鏡像を含む他のコピーがすべてハイライトされます。**はい**ですべて置き換え、**いいえ**なら選択したものだけをブロックにし、**個別確認**なら 1 つずつ決めます。

## 寸法認識（`pdfdim`）

1. 寸法のある範囲を選択します。
2. 次の寸法を認識します。
   - **長さ寸法**：任意の角度、矢印が内側でも外側でも、建築用の斜線端末、直列寸法。
   - **半径・直径寸法**：円に触れる矢印と、`R…` または `Ø…` の文字。
   - **角度寸法**：両端に矢印のある円弧。
3. ブロックと同様に**はい**／**いいえ**／**個別確認**を選びます。

寸法は文字高と矢印サイズが PDF に合った `PDF_DIM` スタイルを使います。長さ尺度は寸法値から読み取った図面尺度に設定されるので、1:100 の図面でも実際の値が表示されます。測定値と合わない文字や記号付きの文字は、そのまま残ります。

::: tip
図形を実寸にしたい場合は先に `pdfscale` を実行してください。その後の `pdfdim` では尺度が 1:1 になります。
:::
