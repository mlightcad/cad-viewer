# PDF 図面の変換

PDF 図面には印刷された形しか残っていません。曲線はベジェパスになり、文字はストロークになっていることが多く、寸法やブロックはばらばらの線になっています。リボンの **AI** タブにある **PDF** パネルで、こうした図面を編集できる CAD オブジェクトに戻せます。確実に判断できるものは読み込み時に自動で変換され、それ以外は見本を選ぶか、見つかった結果を確認して変換します。

| ボタン | コマンド | 内容 |
|---|---|---|
| PDF 読み込み | `ipdf` | PDF の 1 ページを読み込み、曲線・ブロック・線の太さ・線種を復元 |
| 尺度校正 | `pdfscale` | 既知の距離 1 か所から実寸に尺度変更 |
| 文字認識 | `pdftext` | 分解された文字のストロークを文字に戻す |
| ブロック作成 | `pdfblock` | 繰り返し出てくる図形をブロックに戻す |
| 寸法認識 | `pdfdim` | 分解された寸法を寸法オブジェクトに戻す |

これらのコマンドには**書き込み**モードが必要です。おすすめの順序：`ipdf` → `pdfscale` → `pdftext` → `pdfblock` → `pdfdim`。

## 読み込み（`ipdf`）

1. PDF ファイルを選びます。
2. 複数ページのファイルなら、ページ番号を入力します。
3. 挿入点を指定します。Enter で原点に配置されます。オプション：
   - **尺度**：読み込み時の一律の倍率。
   - **曲線**：曲線認識のオン／オフ。

自動で復元されるもの：

- **曲線**：ベジェの円・円弧・楕円は円・円弧・楕円に、線と円弧が混ざった輪郭は円弧セグメント付きのポリラインになります。短い線に分割済みの円弧は当てはめ直され、自由曲線はスプラインになります。
- **ブロック**：同じ PDF フォームで何度も描かれた内容は 1 つのブロック（`PDF_FORM_n`）になり、回転・鏡像のものも含めて各所がブロック参照になります。
- **スタイル**：線幅は線の太さに、破線は `PDF_DASH_*` 線種に、文字は `PDF_<フォント>` 文字スタイルになります。1 行が分割された文字はつなげられます。
- **整理**：完全に重なった重複輪郭は取り除かれます。

塗りつぶし領域は既定では輪郭として読み込まれます。組み込み側は `fillHatches` オプションでソリッドハッチングにできます。

## 尺度校正（`pdfscale`）

PDF は通常 1:50 や 1:100 などの尺度で印刷されています。

1. 尺度変更するオブジェクトを選択します。
2. 長さがわかっている距離（寸法の入った辺など）の両端を指定します。
3. 実際の長さを入力します。

選択に分解された寸法が含まれていれば、寸法値から推定した尺度で実際の長さがあらかじめ入力されます。Enter で確定できます。

## 文字認識（`pdftext`）

1. 文字のある範囲を選択します。枠などの大きな線は無視されます。
2. ストロークが文字行にまとめられ、1 行ずつハイライトされます。その行の文字を入力して確定します。空欄ならその行をスキップし、Esc で終了します。
3. 確定した文字の形はすべて記憶されます。既知の形だけでできた行は確認なしで変換されるので、入力すればするほど手入力は減ります。

記憶した形はブラウザに保存されるため、同じフォントを使う別の図面でも役立ちます。CAD Agent に画像対応の AI モデルが設定されていれば、各行に文字の候補も表示されます。

## ブロック作成（`pdfblock`）

1. 繰り返し出てくる記号のうち**1 つ**のオブジェクトを選択します。
2. ブロックの基点を指定します。**尺度**オプションで大きさの違うコピーも一致の対象になります。
3. ブロック名を確認します。
4. 回転・鏡像を含む他のコピーがすべてハイライトされます。**はい**ですべて置き換え、**いいえ**なら選択したものだけをブロックにし、**個別確認**なら 1 つずつ決めます。

## 寸法認識（`pdfdim`）

1. 寸法のある範囲を選択します。
2. 次の寸法を認識します。
   - **長さ寸法**：任意の角度、矢印が内側でも外側でも、建築用の斜線端末、直列寸法。
   - **半径・直径寸法**：円に触れる矢印と、`R…` または `Ø…` の文字。
   - **角度寸法**：両端に矢印のある円弧。
3. ブロックと同様に**はい**／**いいえ**／**個別確認**を選びます。

寸法は文字高と矢印サイズが PDF に合った `PDF_DIM` スタイルを使います。長さ尺度は寸法値から読み取った図面尺度に設定されるので、1:100 の図面でも実際の値が表示されます。測定値と合わない文字や記号付きの文字は、そのまま残ります。

::: tip
図形を実寸にしたい場合は先に `pdfscale` を実行してください。その後の `pdfdim` では尺度が 1:1 になります。
:::
