# ユーザーインターフェース

MLightCAD Viewer は AutoCAD に類似したクラシックな三段構成レイアウトを採用しています：上部リボン、中央キャンバス、下部ステータスバー。

## 全体レイアウト

```
┌───────────────────────────────────────────────┐
│  リボン（上部）                                 │
├───────────────────────────────────────────────┤
│                                               │
│           キャンバス + オーバーレイ              │
│    ┌──────┐                                  │
│    │右側  │  ドッキングパネル（レイヤー、プロパティなど）│
│    │ツール│                                  │
│    │バー  │                                  │
│    └──────┘                                  │
│                                               │
├───────────────────────────────────────────────┤
│  ステータスバー                                 │
└───────────────────────────────────────────────┘
```

## リボン（上部）

リボンはタブ（Tab）とグループ（Group）でコマンドボタンを整理しています。

### ファイル

| ボタン | 説明 |
|---|---|
| 開く | DWG / DXF ファイルを開く |
| DXF 書き出し | 現在の図面を DXF 形式で書き出す |
| PNG 書き出し | キャンバスを PNG 画像として書き出す |

### 作図

Line、Circle、Arc、Rect、Polyline、Hatch などの作図コマンドを含みます。これらのコマンドはレビューモードでは使用できません。

### レイヤー

レイヤーのオン/オフ、凍結/解凍、ロック、分離などのレイヤー操作。

### 変更

Move、Copy、Offset などの変更コマンド。

### 計測

距離、角度、面積、円弧長、連続計測、座標点。[計測機能の説明](/ja/guide/measure/overview)を参照してください。

### 注釈

矢印、修正クラウド、長方形、円、テキスト、引出注釈（Callout）、ハイライト、スタンプなど。[注釈機能の説明](/ja/guide/markup/overview)を参照してください。

## 右側ツールバー

キャンバス右側に浮かぶ垂直ツールバーで、よく使うツールにすばやくアクセスできます：

- **選択**：エンティティの選択と移動
- **パン**：ドラッグしてビューをパン
- **全体ズーム**：すべての図形を中央に表示
- **ウィンドウズーム**：範囲選択してズーム
- **レイヤー管理**：レイヤーパネルを開く
- **背景切替**：明/暗背景の切替
- **閲覧モード**：集中して閲覧するフルスクリーンモードに移行
- **計測ツール群**：計測ツールパネルをポップアップ
- **注釈ツール群**：注釈ツールパネルをポップアップ（レビューモードで表示）

## ドッキングパネル

パネルはキャンバス右側にドッキングするか、フローティングウィンドウとしてドラッグできます。よく使うパネル：

| パネル | 説明 |
|---|---|
| レイヤー | すべてのレイヤーをリスト表示。オン/オフ、ロック、凍結、分離などをサポート |
| プロパティ | 選択したエンティティのプロパティ情報を表示 |
| 計測リスト | 現在の図面内のすべての計測項目をリスト表示。クリックで該当計測に位置合わせ |
| レビュー（注釈） | すべての注釈をリスト表示。注釈メタデータの編集、クリアなどをサポート |
| 統計 | 図面内のブロックの使用状況を集計 |
| 欠落リソース | 図面内で欠落しているフォントや外部参照を通知 |

## ステータスバー

ステータスバーは画面下部にあり、左から右へ順に：

| 領域 | 説明 |
|---|---|
| レイアウトタブ | モデル空間 / レイアウトの切替 |
| 座標 | 現在のカーソル位置の座標を表示（デスクトップ版のみ） |
| OSNAP | オブジェクトスナップモードのオン/オフと設定 |
| ORTHO | 直交モードのオン/オフ |
| POLAR | 極軸トラッキングのオン/オフと角度増分 |
| 線幅表示 | 線幅の太さを表示するかどうかを制御 |
| 動的入力 | 動的入力のオン/オフ |
| テーマ切替 | 明/暗テーマ |
| フルスクリーン | フルスクリーンモード |

## レビューモード

注釈コマンドを実行すると、ビューアは自動的に**レビューモード**に入ります。このとき DWG/DXF 背景は読み取り専用となり、すべての注釈と計測はオーバーレイとして表示されます。注釈コマンドを終了してもレビューモードは維持され、手動で編集モードに切り替えるまで維持されます。

レビューモードでは注釈コマンドが自動的に利用可能になります。編集モードでは注釈ツールを手動で有効化する必要があります。
