# ジェスチャー

## デスクトップ（マウス）

| 操作 | 効果 |
|---|---|
| 左クリック | 点を拾う / エンティティを選択 |
| 左ドラッグ | 範囲選択 / エンティティをドラッグ |
| ホイール | ビューをズーム |
| 中ボタンまたは Shift + 中ボタンドラッグ | ビューをパン |
| 右クリック | コマンド外：コンテキストメニューを表示。コマンド中：Enter 確定と同等 |
| Esc | 現在のコマンドをキャンセル |
| Enter / スペース | 現在のステップを確定、または前のコマンドを繰り返す |
| Ctrl + Z | 元に戻す |
| Ctrl + Y | やり直し |

## モバイル（タッチ）

### 閲覧モード

図面閲覧時に以下のジェスチャーをサポートします：

| ジェスチャー | 効果 |
|---|---|
| 一本指パン | 図面領域を一本指でタッチして移動し、図面の位置を変更 |
| 二本指パン | 図面領域を二本指でタッチし、指間距離を保ったまま移動して、図面の位置を変更 |
| ピンチイン/アウト | 二本指の間隔を変えて、ビューを拡大または縮小 |

### 編集モード

作図・編集中は、閲覧ジェスチャーに加えて以下をサポートします：

| ジェスチャー | 効果 |
|---|---|
| 一本指タップ | 作図時にタップで点を作成。コマンド未実行状態では、オブジェクトをタップすると選択 |
| 一本指長押し + スワイプ | 窓選択 / 交差窓選択 |
| 一本指タップ + スワイプ | エンティティ作成時、タップした点をマークした後スワイプでその点位置を再調整可能。オブジェクト編集時、選択したグリップをタップしてドラッグし、グリップストレッチやズームを実行 |
| タップ点入力 | 一本指で画面を軽くタップ——移動なし、すばやく離す（0.5 秒未満）——1 点を入力 |
| ドラッグ点入力 | 一本指で画面を 0.5 秒以上長押ししてドラッグ選択モードに入り、対象位置まで移動して離すと入力完了 |

### 範囲選択の方向

AutoCAD と同様に、範囲選択の方向で選択モードが決まります：

- **左から右へ**：窓選択——矩形に完全に含まれるエンティティのみ選択
- **右から左へ**：交差選択——矩形と交差するエンティティがすべて選択
