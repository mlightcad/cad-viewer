# 角度計測

3 本の線で構成される角度（頂点 → 1 本目の辺 → 2 本目の辺）を計測します。

## 操作手順

1. クリックして角度の**頂点**を選択
2. クリックして**1 本目の辺上の点**を選択
3. クリックして**2 本目の辺上の点**を選択

## プレビュー

ステップ 2 の完了後、破線 arm1 + 実線 arm2 のゴムバンド + 角度バッジを表示します。

## 角度計算

内角（包含角）を使用し、範囲は 0° ~ 180° です。

## 表示

角度バッジは角度二等分線方向に沿って頂点の上に配置されます。

## 作成後

3 つの点すべてに grip があり、いずれかをドラッグすると角度が再計算されます。
