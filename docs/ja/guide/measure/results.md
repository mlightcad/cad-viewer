# 結果を確認

現在の図面内のすべての計測結果を確認・管理します。

## 計測パネル

**計測**パネルを開くと完全な計測リストが表示されます。タイプでフィルタ可能：

- すべて
- 距離
- 角度
- 面積
- 弧長
- 座標

各レコードには以下が表示されます：

- タイプアイコン
- 計測値（単位付き）
- 所属レイアウト

## 選択と位置合わせ

- パネル内の計測をクリック → キャンバスが自動的にその計測位置までズーム
- キャンバス内の計測をクリック → パネル内の該当項目をハイライト

## 表示 / 非表示

- ステータスバーの計測可視性ボタンで全計測を一括表示/非表示可能
- 非表示にしても計測データは保持され、視覚的に見えなくなるだけです

## クリア

- 個別クリア：選択後 **Delete** を押す
- 全クリア：パネル下部の「すべてクリア」ボタン
- クリア操作は元に戻せます
