# 円弧長計測

円弧の長さを計測します。2 つのモードをサポートします。

## 自動ロックモード（推奨）

最初の点が図面内の既存の CIRCLE、ARC、またはポリライン bulge 上にある場合、自動的にロックモードに入ります：

- カーソルが円/円弧上に拘束
- 円形 snap インジケーターを表示
- マウスの掃引方向に沿って自動的に円弧を生成

**Ctrl** で大弧 / 小弧の方向を切替できます。

## 三点フリーモード

最初の点がいずれの弧上にもない場合、自動的に三点モードに入ります：

1. 始点
2. 通過点
3. 終点——円弧をリアルタイムプレビュー

## 表示

円弧の Canvas 描画 + 弧長バッジ。

## 作成後

端点 grip をドラッグして調整できます。
