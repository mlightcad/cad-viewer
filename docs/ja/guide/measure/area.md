# 面積計測

いくつかの点で囲まれた多角形の面積を計測します。

## 操作手順

1. 最初の点をクリック
2. 後続の頂点を順にクリック——半透明塗りつぶし + 破線の輪郭をリアルタイムプレビュー
3. **Enter** または **Esc** で終了、または最初の頂点に近い位置をクリックすると自動的に閉じる

## 閉条件（自動閉）

- 始点から約 14px 以内の距離をクリック
- 現在の最後の頂点に非常に近い距離をクリック
- 新しい線分が既存の線分を横切る（自己交差が形成されると自動的に閉じる）

## 面積計算

靴紐公式（Shoelace Formula）を使用します。

## 表示

面積バッジは多角形の重心位置に配置されます。

## 作成後

すべての頂点に grip 点があり、いずれかの頂点をドラッグすると面積がリアルタイムで再計算されます。
