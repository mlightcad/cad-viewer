# MLightCAD の基礎

本プロジェクトでは、`cad-viewer` と `cad-simple-viewer` という 2 つのビューアを提供しています。どちらを選択するかは、プロジェクトの要件と必要な統合レベルによって決まります：

## **cad-viewer** を使用する場合：

- モダンな UI、ダイアログ、ツールバー、状態管理を備えた**すぐに使える Vue 3 コンポーネント**が必要な場合。
- 高性能な CAD ビューア/エディタを、最小限の設定で Vue アプリケーションにすばやく組み込みたい場合。
- ファイルの読み込み、レンダリング、レイヤ/エンティティ管理、ユーザー操作をすぐに利用できるソリューションを希望する場合。
- 最適化された SVG および THREE.js レンダラー、国際化、テーマ設定とのシームレスな統合を希望する場合。
- 独自の UI をゼロから構築する必要が**ない**場合。

**推奨:** 洗練されたユーザーインターフェースで CAD ファイルを表示する必要があるほとんどの Web アプリケーション、ダッシュボード、プラットフォーム。

## **cad-simple-viewer** を使用する場合：

- UI フレームワークへの依存なしに、**CAD のコアロジックのみ**（ドキュメント管理、コマンドスタック、レンダリングエンジン統合）が必要な場合。
- **独自のカスタム UI** を構築する場合、または CAD 機能を Vue 以外の環境や Web 以外の環境に統合する場合。
- 大規模な CAD ファイルを扱うための最大限の柔軟性と性能を必要とし、ロジックを独自のレンダリング層または UI 層に接続する予定がある場合。
- 必要最小限の CAD 操作とキャンバスレンダリングのみを提供する、フレームワーク非依存のソリューションを希望する場合。

**推奨:** カスタム統合、ヘッドレス CAD 処理、または高度にカスタマイズされた CAD ソリューションを構築する上級ユーザー。

**まとめ表：**

| パッケージ             | UI の提供 | フレームワーク | 用途                                      |
|---------------------|-------------|-----------|-----------------------------------------------|
| `cad-viewer`        | あり         | Vue 3     | モダンな UI を備えたすぐに使える CAD ビューア/エディタ       |
| `cad-simple-viewer` | なし          | なし      | カスタム用途またはヘッドレス用途向けのコア CAD ロジック      |

詳細は [**Simple Viewer の統合**](./integrate-simple-cad-viewer) と [**Vue コンポーネントの統合**](./integrate-cad-viewer-component) を参照してください。
