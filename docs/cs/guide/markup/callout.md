# Callout

Samostatná kombinace leaderské čáry + textové bubliny, slouží k poznámkování detailu z dálky.

## Kroky interakce

1. Klepnutím vyberte špičku šipky **tip** (směřuje na anotovanou pozici)
2. Tažením umístěte pozici kotvy **anchor** textové bubliny – náhled leaderské čáry + bubliny v reálném čase
   - **Chytré připojení**: pokud první bod padne na existující cloud / obdélník / kruhový obrys, automaticky se použije tento tvar a přidá se pouze leaderská čára a bublina
3. Do bubliny zadejte text

## Tři úchopové body

- **tip**: koncový bod šipky, tažením upravíte směr
- **anchor**: koncový bod bubliny, tažením upravíte pozici bubliny
- **střed**: současně přesune tip a anchor, celkové posunutí

Dvojklikem na text bubliny lze vstoupit do vložené úpravy.
