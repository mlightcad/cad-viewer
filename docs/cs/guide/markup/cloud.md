# Cloud (revizní cloud)

Vykreslí obdélníkový rámeček s cloudem, často používaný pro označení oblastí určených k úpravám.

## Kroky interakce

1. Klepnutím vyberte první rohový bod
2. Klepnutím vyberte protilehlý rohový bod – náhled obrysu cloudu v reálném čase
3. Po dokončení lze zvolit, zda ke cloudu připojit Callout (leaderská čára + textová bublina)
