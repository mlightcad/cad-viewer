# Text

Na určenou pozici umístí čistý textový štítek bez leaderské čáry.

## Kroky interakce

1. Klepnutím vyberte pozici pro umístění textu
2. Do vyskakovacího vloženého editačního pole zadejte text
3. Klepnutím jinam nebo stisknutím **Esc** dokončete

Po vytvoření lze text přesunout tažením středového úchopového bodu. Dvojklikem lze znovu upravit obsah textu.
