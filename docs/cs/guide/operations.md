# Způsoby ovládání

## Desktop (myš)

| Operace | Účinek |
|---|---|
| Klepnutí levým tlačítkem | vyzvednutí bodu / výběr entity |
| Tažení levým tlačítkem | výběr oknem / přesun entity |
| Kolečko | přiblížení pohledu |
| Tažení prostředním tlačítkem nebo Shift + prostřední tlačítko | posun pohledu |
| Pravé tlačítko | mimo příkaz: kontextová nabídka; během příkazu: odpovídá Enter (potvrzení) |
| Esc | zrušení aktuálního příkazu |
| Enter / mezerník | potvrzení aktuálního kroku nebo opakování předchozího příkazu |
| Ctrl + Z | zpět |
| Ctrl + Y | znovu |

## Mobilní zařízení (dotyk)

### Režim prohlížení

Při prohlížení výkresu jsou podporována následující gesta:

| Gesto | Účinek |
|---|---|
| Posun jedním prstem | dotek jedním prstem na kresebnou oblast a pohyb, změní pozici výkresu |
| Posun dvěma prsty | dotek dvěma prsty na kresebnou oblast, při zachování vzdálenosti mezi prsty dojde k pohybu, změní pozici výkresu |
| Stažení dvěma prsty | změna vzdálenosti mezi prsty, přiblížení nebo oddálení pohledu |

### Režim úprav

Při kreslení a úpravách jsou nad rámec prohlížecích gest podporovány:

| Gesto | Účinek |
|---|---|
| Klepnutí jedním prstem | při kreslení klepnutím vytvoří bod; bez aktivního příkazu klepnutí na objekt jej vybere |
| Dlouhý stisk jedním prstem + tažení | výběr oknem / křížový výběr oknem |
| Klepnutí jedním prstem + tažení | při tvorbě entity lze po označení bodu tažením přemístit tento bod; při úpravě objektu lze po vybrání úchopového bodu tažením provést úchopové natažení nebo škálování |
| Zadání bodu klepnutím | lehké dotek jedním prstem – bez posunu, rychlé uvolnění (do 0,5 s) – zadání bodu |
| Zadání bodu tažením | dlouhý stisk prstem na obrazovku přes 0,5 s, přechod do režimu výběru tažením, po přesunu na cílovou pozici uvolněním dokončíte zadání |

### Směr výběru oknem

Stejně jako v AutoCADu směr výběru oknem určuje režim výběru:

- **Zleva doprava**: výběr oknem – vybrány jsou pouze entity, které jsou zcela uvnitř obdélníku
- **Zprava doleva**: křížový výběr – vybrány jsou všechny entity protínající obdélník
