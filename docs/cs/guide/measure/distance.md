# Měření vzdálenosti

Změří přímou vzdálenost mezi dvěma body.

## Kroky interakce

1. Klepnutím vyberte první bod
2. Klepnutím vyberte druhý bod

## Náhled

Plátno vykreslí úsečku se šipkami na obou koncích, uprostřed se zobrazí odznak s délkou.

## Po vytvoření

Oba koncové úchopové body lze nezávisle táhnout, hodnota se aktualizuje v reálném čase.
