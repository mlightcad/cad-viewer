# Měření souřadnic

Změří souřadnice X / Y určeného bodu.

## Kroky interakce

1. Klepnutím vyberte cílový bod (v kombinaci s OSNAP lze přesně zachytit koncové body, průsečíky atd.)

## Zobrazení

Vedle bodu se zobrazí odznak se souřadnicemi ve formátu `X xxx.xx  Y yyy.yy`.
