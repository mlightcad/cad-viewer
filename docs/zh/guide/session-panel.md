# 命令会话面板（移动端）

在桌面端，命令执行过程中会在光标附近显示**动态输入框（Dynamic Input）**，用户可以直接在输入框中键入距离、角度等数值，也可以通过 **Enter** 键确认、**Esc** 键取消。在移动端，由于没有物理键盘，这一套交互方式无法直接复用。

**命令会话面板**（Session Panel）就是移动端专门用来替代桌面端动态输入 + 键盘的交互组件。它固定在屏幕底部，在命令执行期间自动弹出，显示当前命令提示、实时度量值，并提供虚拟的 **确定**（✓）和 **取消**（×）按钮，分别等价于桌面端的 **Enter** 和 **Esc**。

## 面板组成

展开状态下，面板从上到下分为以下几个区域：

### 会话附件 / 标题栏

面板第一行的左侧显示当前命令安装的 **会话附件**（Session Accessory）。不同命令会安装不同的会话附件——测量和批注命令会安装**绘图样式附件**（Draw-style Session Accessory），用于控制颜色和文字大小；多段线、文字等命令则可能安装各自专属的附件控件。如果当前命令**没有安装任何会话附件**，第一行左侧就会显示命令提示文字（此时第二行的提示行不再出现）。

下面演示的是测量 / 批注命令的场景，第一行安装了绘图样式附件：

| 控件 | 图标 | 作用 |
|---|---|---|
| 颜色按钮 | <span style="display:inline-block;width:14px;height:14px;border-radius:50%;background:#1a8cff;border:1px solid #555;"></span> | 打开 ACI 颜色选择面板或对话框，设置当前命令的绘图颜色 |

标题栏右侧还有两个圆形图标按钮：

| 按钮 | 图标 | 作用 |
|---|---|---|
| 帮助 | ? | 打开帮助文档全屏面板 |
| 收起/展开 | ▼ / ▲ | 切换紧凑模式与展开模式 |

### 提示行

仅当当前命令**安装了会话附件**时，面板第二行才会出现提示行——它显示命令的**提示文字**（如 "指定第一个点"），以及该命令的可选**关键字标签**（如 `[放弃(U)/继续(C)]`）。提示文字左对齐，根据页面语言自动切换。

如果当前命令没有安装会话附件，提示文字会直接显示在第一行左侧（替代会话附件的位置），不再有独立的第二行提示行。

点击关键字标签可以直接触发该选项，替代桌面端在命令行中键入关键字的操作。

### 度量区

跟随用户手指移动，面板实时显示当前位置的度量数值。度量内容取决于命令执行状态：

| 状态 | 显示项 | 说明 |
|---|---|---|
| 尚未确定第一点 | **X** / **Y** | 当前光标位置的绝对坐标 |
| 已确定第一点（相对模式） | **长度** / **角度** | 从第一点到当前位置的距离和角度 |
| 已确定第一点（相对模式） | **ΔX** / **ΔY** | 从第一点到当前位置的 X、Y 方向增量 |

平板端与手机端的度量布局不同：手机端各度量值独立成行，取消和确认按钮分别嵌在度量行右侧；平板端度量值横向排列，取消和确认按钮统一放在最右侧的共享区域。

### 确定 / 取消按钮

| 按钮 | 图标 | 桌面端等价 | 作用 |
|---|---|---|---|
| **确定** | ✓（蓝色圆形） | `Enter` / 空回车 | 确认当前输入或接受默认值 |
| **取消** | ×（灰色圆形） | `Esc` | 终止当前命令 |

当命令不支持空回车（即必须由用户指定值）时，**确定**按钮会被禁用（变灰）。

## 紧凑模式

点击标题栏右侧的 ▼ 按钮，面板会切换到**紧凑模式**（Compact Mode）。紧凑模式下面板高度从多行缩小为单行，提示行、度量区和选项标签全部隐藏，只保留：

- **会话附件**（如有）
- **展开** 按钮（▲，方向反转）
- **取消**（×）/ **确定**（✓）按钮

紧凑模式的设计目的是在命令执行过程中让画布获得更大的可视区域，同时保留最核心的操作能力。在紧凑模式下点击 **展开** 按钮即可恢复展开模式。

## 手机端 vs 平板端

命令会话面板会自动检测设备屏幕宽度并适配布局：

| 特性 | 手机（≤600px） | 平板（>600px） |
|---|---|---|
| 面板宽度 | 撑满屏幕宽度 | 居中显示，固定 480px 宽度，带圆角和阴影 |
| 度量值排列 | 纵向堆叠，每项占一行 | 横向排列，两组度量并排 |
| 按钮位置 | 取消/确认分别嵌入不同度量行右侧 | 取消/确认集中在右侧共享区域 |
| 紧凑模式样式 | 通栏单行 | 固定宽度、单行居中 |

## 与桌面端的对应关系

| 桌面端操作 | 移动端会话面板对应 |
|---|---|
| 动态输入框（DYN）显示距离/角度 | 度量区实时显示长度、角度、ΔX、ΔY |
| 在命令行键入关键字选项 | 点击选项标签（Keyword Chips） |
| `Enter` 空回车接受默认值 | 点击 **确定**（✓）按钮 |
| `Esc` 取消命令 | 点击 **取消**（×）按钮 |
| 命令行显示 `Specify first point:` | 提示行显示同样的提示文字 |
