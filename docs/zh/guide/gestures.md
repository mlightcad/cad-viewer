# 手势

## 桌面端（鼠标）

| 操作 | 效果 |
|---|---|
| 左键单击 | 拾取点 / 选择实体 |
| 左键拖拽 | 框选 / 拖动实体 |
| 滚轮 | 缩放视图 |
| 中键或 Shift + 中键拖拽 | 平移视图 |
| 右键 | 在命令外：弹出上下文菜单；在命令中：相当于 Enter 确认 |
| Esc | 取消当前命令 |
| Enter / 空格 | 确认当前步骤或重复上一个命令 |
| Ctrl + Z | 撤销 |
| Ctrl + Y | 重做 |

## 移动端（触摸）

### 浏览模式

查看图纸时支持以下手势：

| 手势 | 效果 |
|---|---|
| 单指平移 | 单指触摸绘图区域并移动，改变图纸位置 |
| 双指平移 | 双指触摸绘图区域，保持指间距离不变移动，改变图纸位置 |
| 两指捏合 | 改变两指间距，放大或缩小视图 |

### 编辑模式

绘制和编辑状态下，在浏览手势的基础上还支持：

| 手势 | 效果 |
|---|---|
| 单指点击 | 绘制时点击创建一个点；无命令状态下，点击对象即选中它 |
| 单指长按 + 滑动 | 窗选 / 窗交框选 |
| 单指点击 + 滑动 | 创建实体时，点击点标记后滑动可重新调整该点位置；编辑对象时，点击选中夹点后拖动，可执行夹点拉伸或缩放 |
| 单击点输入 | 单指轻点屏幕——没有位移、迅速抬起（小于 0.5 秒）——输入一个点 |
| 拖动点输入 | 单指长按屏幕超过 0.5 秒，进入拖动选取模式，移动到目标位置后抬起完成输入 |

### 框选方向

和 AutoCAD 一样，框选的方向决定了选择模式：

- **从左到右**：窗口选择——只有完全在矩形内的实体被选中
- **从右到左**：交叉选择——与矩形相交的实体都被选中
