# 放大镜（移动端）

在触摸屏上精确拾取点时，手指会遮挡目标位置。放大镜提供一种视觉辅助：在屏幕左上角显示一个方形放大镜 HUD，放大输入点附近区域的内容，帮助你在密集图纸中精确选择小对象。

<MagnifierAnimation />

## 工作方式

- 当命令需要用户确定一个点时，在屏幕上**长按约 1 秒**，左上角会自动显示方形放大镜 HUD。
- 放大镜放大的区域跟随当前输入点：放大镜帮助你看清输入点附近的精确位置，而不被手指遮挡。
- 放大镜仅提供视觉辅助，不改变输入位置。

## 与模拟鼠标的关系

放大镜在长按后始终显示，模拟鼠标开关只影响放大镜放大**哪个位置**：

- **模拟鼠标开启（默认）**：输入点偏移到手指上方约 52px 处的十字光标位置，放大镜放大的是十字光标附近区域。
- **模拟鼠标关闭**：输入点为手指触点，放大镜放大的是手指触点附近区域。

模拟鼠标是一个开关按钮，可在**设置**中切换，也可在绘制过程中随时切换。
