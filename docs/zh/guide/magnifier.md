# 放大镜（移动端）

在触摸屏上精确拾取点时，手指会遮挡目标位置。放大镜提供一种视觉辅助：在屏幕左上角显示一个方形放大镜 HUD，放大手指触点附近区域的内容，帮助你在密集图纸中精确选择小对象。

## 工作方式

- 长按屏幕后，左上角会显示方形放大镜 HUD，放大手指触点附近区域的内容。
- 放大镜帮助你看清手指下方的精确位置。
- 实际输入位置仍以手指触点为准，放大镜仅提供视觉辅助，不改变输入位置。

## 与模拟鼠标的关系

放大镜是触摸拾取的基础视觉辅助。模拟鼠标默认开启，用手指上方的十字光标替代放大镜进行输入。在**设置**中关闭模拟鼠标后，长按屏幕改为显示放大镜 HUD：

- **模拟鼠标开启（默认）**：手指上方显示十字光标，输入点偏移到光标位置。
- **模拟鼠标关闭**：左上角显示方形放大镜 HUD，放大手指触点附近区域，输入位置仍为手指触点。

模拟鼠标是一个开关按钮，可在绘制过程中随时切换。
