# 模拟鼠标（移动端）

在触摸屏上绘图时，手指本身会遮挡屏幕上的目标位置，容易造成误操作。模拟鼠标就是为了解决这个问题：把输入点从手指触点"抬"到手指上方，用十字光标代替手指进行精确输入。

<TouchPointAnimation />

## 工作方式

- **默认开启**。
- 执行绘制等命令时，手指**长按**屏幕，手指上方会显示十字形模拟鼠标光标（位于手指上方约 52px 处）。
- 手指触点输入变为**十字光标点输入**：实际输入位置以十字光标为准，而不是手指接触的位置，从而避免手指遮挡造成的偏差。

## 开启 / 关闭

- 可以在**设置**中开启或关闭模拟鼠标。
- 绘制过程中也支持随时切换开关。
