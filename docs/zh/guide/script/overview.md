# 脚本功能说明

脚本功能用于在图纸上执行自定义的 JavaScript 代码，完成查询、统计、批量编辑和选择高亮等操作。脚本通过 `cad` 对象与图纸交互，无需连接外部模型或配置 API Key。

脚本功能由 `@mlightcad/cad-script-plugin` 插件提供。只有在应用中加载了该插件后，脚本面板才可用。

## 打开脚本面板

- 在命令行输入 `cadscript` 并回车
- 或在工具面板中点击「脚本」标签页

脚本面板包含：

- **脚本编辑器**：编写 JavaScript 函数体
- **运行按钮**：执行脚本（快捷键 `Ctrl+Enter`）
- **帮助**：用当前界面语言打开本说明
- **示例**：按描述搜索内置脚本，并载入编辑器
- **结果区域**：以可折叠的 JSON 树显示返回值，并显示日志、错误信息和实体变化。拖动编辑器与结果区域之间的分割线可调整高度。

## 脚本执行方式

脚本在严格模式下运行，自动包裹为函数：

```javascript
function __cadScript(cad) {
  // 你的代码写在这里
}
```

函数唯一参数是 `cad`，通过它访问图纸数据和执行操作。

## 限制

- 脚本有时间和步数限制，超时或超步会被自动停止
- 禁止访问页面全局对象（`window`、`document`、`fetch` 等）
- 禁止 `import` / `export` / `this` 等语法
- 返回值必须是可 JSON 序列化的数据
- 编辑操作必须在 `cad.edit.transaction` 中执行，且图纸需处于可编辑状态

## 草稿保存

编辑器内容会自动保存到浏览器本地存储，刷新页面后恢复上次编辑的脚本。
