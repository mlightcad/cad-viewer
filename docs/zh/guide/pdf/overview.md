# PDF 图纸转换

PDF 图纸只保留了打印出来的样子：曲线变成贝塞尔路径，文字常常变成笔画，标注和块被拆成零散的线条。**AI** 功能区标签页里的 **PDF** 面板可以把这样的图纸恢复成可编辑的 CAD 对象。能确定的部分在导入时自动转换，其余部分由你给出一个示例，或确认程序找到的结果。

| 按钮 | 命令 | 作用 |
|---|---|---|
| 导入 PDF | `pdfimport` / `-pdfimport` | 导入一页 PDF，并恢复曲线、块、线宽和线型 |
| 校准比例 | `pdfscale` | 根据一段已知距离把导入的图形缩放到实际尺寸 |
| 识别文字 | `pdftext` | 把被打散的文字笔画恢复为文字 |
| 创建块 | `pdfblock` | 把重复出现的图形恢复为块 |
| 识别标注 | `pdfdim` | 把被打散的标注恢复为标注对象 |
| 识别填充 | `pdfhatch` | 把被打散成短线段的图案填充恢复为带图案的填充 |

这些命令需要**可写**模式。推荐顺序：`pdfimport` → `pdfscale` → `pdftext` → `pdfblock` → `pdfdim` → `pdfhatch`。

## 导入（`pdfimport`）

1. 选择 PDF 文件，随后打开“输入 PDF”对话框。
2. 在“要输入的页面”中选择页码（仅多页文件）。预览区显示该页，旁边的缩略图按钮可列出所有页面。“浏览...”可换一个文件。
3. 在“位置”中输入插入点 X/Y（默认为原点），或勾选“在屏幕上指定插入点”，在点击“确定”后到图中拾取。“比例”为导入时的统一缩放。
4. 在“输入方式”中选择导入方式：
   - **复原图纸**（默认）：尽量复原原始图纸，见下文。
   - **保留 PDF 视觉效果**：完全保留 PDF 的视觉效果。每条路径都成为直线或多段线（曲线被打散），每段文字各成一个文字对象；不做合并、去重，也不生成块。复原后的效果与 PDF 不一致时使用。
5. 点击“确定”。对话框会记住位置、比例和输入方式，供下次 `pdfimport` 使用。

`-pdfimport` 不显示对话框：选择文件后，在命令行中依次提示页码（仅多页文件）和插入点，插入点提示带有“比例”和“模式”选项。直接回车则插到原点。

**复原图纸**模式下自动恢复的内容：

- **曲线**：贝塞尔圆、圆弧、椭圆恢复为圆、圆弧、椭圆。直线和圆弧混合的轮廓恢复为带圆弧段的多段线。已被打成短线的圆弧会重新拟合。其余自由曲线恢复为样条曲线。
- **块**：同一个 PDF Form 画了多次的内容，恢复为一个块（`PDF_FORM_n`），每处是一个块参照，旋转和镜像的也包括在内。
- **样式**：线宽映射为线宽属性，虚线得到 `PDF_DASH_*` 线型，文字得到 `PDF_<字体>` 文字样式。同一行被拆开的文字会合并。
- **清理**：完全重合的重复轮廓会被去掉。

填充区域（彩色色块、填充的标志和文字轮廓）会以其填充颜色导入为实体填充，并保持与页面相同的绘制顺序。集成方可以将 `fillHatches` 选项设为 `false`，只导入轮廓线。

图案填充（ANSI31、砖块、交叉线等）在 PDF 中是成千上万条短线。在**复原图纸**模式下，它们会被重建为图案填充对象：这些线与标准 `acadiso.pat` 图案（或用户定义的单向、双向图案）进行匹配，并还原绘制时的比例、角度和原点。边界取自已绘制的闭合轮廓、PDF 裁剪路径或线段端点。只有重新绘制的图案填充与页面上的线条一致时才会保留，否则这些线仍保持为直线。集成方可以将 `recognizeHatches` 设为 `false`，保留全部直线。

两种模式下，文字都会按其在 PDF 中的宽度拉伸或压缩，因为查看器通常用不同的字体绘制文字。图片（照片、标志、二维码）导入为名为 `PDF_IMAGE_n.png` 的光栅图像；像素只保存在当前打开的图纸中，因为 DWG 和 DXF 以外部文件方式引用图像。透明背景上的黑色图片（如二维码）会放在白底上，与 PDF 页面一致。

## 校准比例（`pdfscale`）

PDF 图纸通常按 1:50、1:100 等比例打印。

1. 选择要缩放的对象。
2. 点取一段已知距离的两个端点，例如一条有标注的边。
3. 输入它的实际长度。

如果所选对象中有被打散的标注，程序会根据标注文字推算出比例，并自动填好实际长度，直接回车即可接受。

## 识别文字（`pdftext`）

1. 选择文字所在的区域。边框等较大的线条会被忽略。
2. 笔画会被归并为文字行，并判断每一行是 **SHX** 文字（开放的线条笔画）还是 **TrueType** 文字（闭合的轮廓）。完全由之前输入过的字形组成的行会被立即识别。
3. 如果配置了支持图片的 AI 模型（`LLMSETTINGS`），其余所有行会一次性发送给它（只需少量请求）。如果识别失败，会显示失败原因（例如 API 密钥无效）。
4. 选项板中会打开**识别文字**面板，图纸中会显示转换结果的预览。面板打开时可以平移和缩放图纸。
   - 分别为 SHX 文字和 TrueType 文字选择已有的**文字样式**或新建一个，并查看它使用的**字体**和**大字体**。与原图不符时可以替换；字体缺失时会提示实际用来显示的字体，修改已有样式的字体时会提示已使用该样式的文字也会改变。默认情况下 SHX 文字使用 `PDF_SHX` 样式（`txt` + `gbcbig`），保持 SHX 文字的外观和大小。
   - 调整**高度比例**，**宽度因子**可以适配原宽度，也可以手动设置。
   - 列表显示每一行的文字及其来源（已学习、OCR、已编辑、未识别），无法识别的行排在最前面。点击某行可在图纸中定位该行；修改或输入文字后按回车跳到下一个未识别的行。输入一行后，复用相同字形的其他行也会自动填好。取消勾选可跳过该行，判断错误的行可以在 SHX 和 TrueType 之间切换。
   - 本应是一段文字却被识别成多行的字符，可以合并为一个多行文字（MTEXT）：按住 Ctrl 或 Shift 单击选择这些行，再点击**合并为多行文字**；或点击**合并相邻字符**，把同一基线上相邻的内容全部合并。位于不同基线的行会成为多行文字中的不同行，并保持原来的行距。点击**拆分**可把合并后的文字拆回原来的行。
   - 勾选**隐藏原始线条**可以只看预览。
5. 点击**应用**完成转换。点击**取消**或关闭选项板则不做任何更改。

您输入过的每个字形都会保存在浏览器中，使用相同字体的其他图纸也能受益。AI 模型识别出的文字不会被记住。整个命令可以一次撤销，转换后的文字也可以像其他文字一样编辑。

## 创建块（`pdfblock`）

1. 选择重复符号中**一个**实例的对象。
2. 指定块基点。**比例**选项可以让大小不同的副本也被匹配。
3. 确认块名。
4. 其余所有副本（包括旋转、镜像的）会被高亮。选择**是**全部替换，**否**只把所选对象做成块，**逐个确认**则一个一个决定。

## 识别标注（`pdfdim`）

1. 框选标注所在区域。
2. 可以识别以下标注：
   - **线性标注**：任意角度，箭头在内侧或外侧，建筑斜线标记，以及连续标注。
   - **半径和直径标注**：箭头碰到圆，并带有 `R…` 或 `Ø…` 文字。
   - **角度标注**：两端都有箭头的圆弧。
3. 和创建块一样，选择**是**、**否**或**逐个确认**。

生成的标注使用 `PDF_DIM` 标注样式，字高和箭头大小与 PDF 一致。它的测量比例因子等于从标注文字读出的图纸比例，所以 1:100 的图纸仍然显示实际数值。与测量值不一致或带有额外符号的文字会原样保留。

::: tip
如果希望图形是实际尺寸，请先运行 `pdfscale`，之后 `pdfdim` 推算出的比例就是 1:1。
:::

## 识别填充（`pdfhatch`）

PDF 只把图案填充保存为许多已按边界裁剪好的短线段。

1. 选择填充区域以及它周围的线条，用交叉窗口框住该区域即可。
2. 规则排列的线段先与 `acadiso.pat` 中的图案（ANSI31、ANSI36、AR-B816 等）匹配，再尝试用户定义的单向或双向线。都不匹配时，会测量间距、错位和虚线段，并生成自定义图案 `PDF_HATCH`。
3. 边界取自所选范围中的闭合轮廓，或者所选直线、圆弧和多段线围成的区域，即使它们相互交叉或伸出边界也可以。孤岛会保留为孔洞。
4. 预览的填充会显示在原线段的位置上。和创建块一样，选择**是**、**否**或**逐个确认**。

只有重新绘制能还原原线段的填充才会被采用，并且只删除被完整重绘的对象。图案比例和角度以图形单位表示，因此按比例 1 导入的填充比例会很小；如需实际数值，请先运行 `pdfscale`。
