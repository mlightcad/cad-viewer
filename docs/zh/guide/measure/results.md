# 看结果

查看和管理当前图纸中的所有测量结果。

## 测量面板

打开**测量**面板，看到完整的测量列表。支持按类型过滤：

- 全部
- 距离
- 角度
- 面积
- 弧长
- 坐标

每条记录显示：

- 类型图标
- 测量值（带单位）
- 所在布局

## 选择和定位

- 点击面板中的测量 → 画布自动缩放到该测量位置
- 点击画布中的测量 → 面板中高亮对应项

## 显示 / 隐藏

- 状态栏的测量可见性按钮可以一键显示/隐藏全部测量
- 隐藏后测量数据仍保留，只是视觉上不可见

## 清除

- 单条清除：选中后按 **Delete**
- 全部清除：面板底部"清除全部"按钮
- 清除可撤销
