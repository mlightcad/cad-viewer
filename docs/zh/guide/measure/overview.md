# 测量功能说明

测量命令用于在图纸上进行临时测量。所有测量结果以 HTML 叠加层的形式显示，**不会写入 DWG/DXF 文件**，可以独立导出和分享。

## 创建测量

选择命令后，按提示依次点击所需的点。拖拽过程中有实时预览（橡皮筋 + 测量值徽章）。

## 编辑测量

- **单击**测量对象选中，显示 grip 点
- **拖拽 grip 点**调整测量，数值实时更新

## 撤销 / 重做

测量操作支持撤销和重做。

## 单位和精度

测量值的显示单位和精度可以在设置中调整，支持毫米 / 厘米 / 米 / 英尺 / 英寸等。这些设置不影响原始 DWG/DXF 文件，只影响测量显示。

## 导入 / 导出

测量数据可以导出为 JSON sidecar 文件（`图纸名.measurement.json`），方便跨图纸、跨设备分享。导入时自动还原所有测量对象及其样式。
