# 测面积

测量由若干点围成的多边形的面积。

## 交互步骤

1. 点击第一个点
2. 依次点击后续顶点——实时预览半透明填充 + 虚线轮廓
3. 按 **Enter** 或 **Esc** 结束，或点击靠近第一个顶点自动闭合

## 闭合条件（自动闭合）

- 点击距离起点约 14px 以内
- 点击距离当前最后一个顶点很近
- 新线段穿越已有线段（形成自相交时自动闭合）

## 面积计算

使用鞋带公式（Shoelace Formula）。

## 显示

面积徽章位于多边形的质心位置。

## 创建后

所有顶点都有 grip 点，拖拽任何一个顶点，面积实时重新计算。
