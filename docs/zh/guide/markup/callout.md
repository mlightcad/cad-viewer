# 标注（Callout）

独立的引线 + 文字气泡组合，用于在远处注释某个细节。

## 交互步骤

1. 点击选择箭头 **tip** 端（指向被注释的位置）
2. 拖拽放置文字气泡 **anchor** 位置——实时预览引线 + 气泡
   - **智能挂载**：如果第 1 个点落在已有的云线 / 矩形 / 圆形框线上，会自动复用该形状，只添加引线和气泡
3. 在气泡中输入文字

## 三个 grip 点

- **tip**：箭头端点，拖拽调整指向
- **anchor**：气泡端点，拖拽调整气泡位置
- **中点**：同时移动 tip 和 anchor，整体平移

双击气泡文字可进入内联编辑。
