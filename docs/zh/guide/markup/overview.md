# 批注功能说明

批注命令用于在图纸上添加审阅标记。执行批注命令时，查看器会自动进入**审阅模式**（DWG/DXF 背景只读）。

所有批注都作为 HTML 叠加层绘制，**不会修改原始 DWG/DXF 文件**。它们通过 JSON sidecar 文件（`图纸名.markup.json`）独立保存和分享。

## 创建批注

大多数批注命令采用 CAD 风格的分步点选交互：

1. 选择命令（功能区 → 批注组，或右侧工具栏批注弹出面板）
2. 根据命令提示依次点击所需的点
3. 拖拽过程中有实时预览（Jig）
4. 完成后批注立即显示在画布上

## 编辑批注

- **单击**批注选中，显示 grip 编辑点
- **拖拽 grip 点**可以调整形状、端点等
- **双击**带文字的批注（文字、Callout、带附加 Callout 的形状）进入内联文字编辑
- 选中后按 **Delete** 键删除

## 撤销 / 重做

批注操作支持撤销和重做。撤销不仅会撤销创建操作，也会撤销 grip 编辑、删除等修改。

## 导入 / 导出

- **导出**：将当前所有批注导出为 JSON 文件下载
- **导入**：加载之前导出的 JSON 文件，还原所有批注

sidecar JSON 文件可跨图纸、跨设备分享。
