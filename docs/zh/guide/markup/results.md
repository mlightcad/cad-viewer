# 看结果

查看和管理当前图纸中的所有批注。

## 批注面板

打开**审阅**面板可以看到完整的批注列表，每条记录显示：

- 批注类型（箭头、云线、文字等图标）
- 创建者
- 创建时间
- 可选：批注文字内容的摘要

## 选择和定位

- 点击面板中的批注 → 画布自动 **focus**（缩放到该批注位置）
- 点击画布中的批注 → 面板中高亮对应项

## 编辑元数据

部分批注可以在面板中编辑 **Comment**（备注）和 **Status**（状态，如 Open / Resolved）等元数据。

## 显示 / 隐藏

- 在面板中可以切换单条批注的可见性
- 右侧工具栏批注工具组中的显示/隐藏按钮可以一键显示/隐藏全部批注

## 清除

- 单条清除：选中后按 **Delete**
- 全部清除：在面板中点击"清除全部"
- 清除可撤销

## 导入 / 导出

面板顶部提供导出和导入按钮，sidecar JSON 文件可跨图纸、跨设备分享。
