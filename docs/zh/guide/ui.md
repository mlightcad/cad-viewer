# 用户界面

MLightCAD Viewer 采用类似 AutoCAD 的经典三段式布局：顶部功能区、中间画布区、底部状态栏。

## 整体布局

```
┌───────────────────────────────────────────────┐
│  顶部功能区（Ribbon）                           │
├───────────────────────────────────────────────┤
│                                               │
│           画布 + 叠加层                        │
│    ┌─────┐                                    │
│    │右侧 │  停靠面板（图层、属性等）             │
│    │工具 │                                    │
│    │栏   │                                    │
│    └─────┘                                    │
│                                               │
├───────────────────────────────────────────────┤
│  状态栏                                        │
└───────────────────────────────────────────────┘
```

## 顶部功能区

功能区以选项卡（Tab）和组（Group）的方式组织命令按钮。

### 文件

| 按钮 | 说明 |
|---|---|
| 打开 | 打开 DWG / DXF 文件 |
| 导出 DXF | 将当前图纸导出为 DXF 格式 |
| 导出 PNG | 将画布导出为 PNG 图片 |

### 绘制

包含 Line、Circle、Arc、Rect、Polyline、Hatch 等绘制命令。这些命令在审阅模式下不可用。

### 图层

图层开/关、冻结/解冻、锁定、隔离等图层操作。

### 修改

Move、Copy、Offset 等修改命令。

### 测量

距离、角度、面积、弧长、连续测量、坐标点。详见 [测量功能说明](/zh/guide/measure/overview)。

### 批注

箭头、云线、矩形、圆形、文字、标注（Callout）、高亮、印章等。详见 [批注功能说明](/zh/guide/markup/overview)。

## 右侧工具栏

浮动在画布右侧的垂直工具栏，提供常用工具的快捷访问：

- **选择**：选择和移动实体
- **平移**：拖动平移视图
- **缩放到全图**：将所有图形居中显示
- **窗口缩放**：框选区域进行缩放
- **图层管理**：打开图层面板
- **切换背景**：明/暗背景切换
- **阅读模式**：进入专注阅读的全屏模式
- **测量工具组**：弹出测量工具面板
- **批注工具组**：弹出批注工具面板（审阅模式下显示）

## 停靠面板

面板可以停靠在画布右侧或作为浮窗拖动。常用面板：

| 面板 | 说明 |
|---|---|
| 图层 | 列出所有图层，支持开/关、锁定、冻结、隔离等操作 |
| 属性 | 显示所选实体的属性信息 |
| 测量列表 | 列出当前图纸中所有测量项，点击可定位到对应测量 |
| 审阅（批注） | 列出所有批注，支持编辑批注元数据、清除等 |
| 统计 | 对图纸中块的使用情况进行统计 |
| 缺失资源 | 提示图纸中缺失的字体或外部参照 |

## 状态栏

状态栏位于界面底部，从左到右依次为：

| 区域 | 说明 |
|---|---|
| 布局标签 | 模型空间 / 布局切换 |
| 坐标 | 显示当前光标位置坐标（仅桌面端） |
| OSNAP | 对象捕捉模式开关和配置 |
| ORTHO | 正交模式开关 |
| POLAR | 极轴跟踪开关和角度增量 |
| 线宽显示 | 控制是否显示线宽粗细 |
| 动态输入 | 动态输入开关 |
| 主题切换 | 明/暗主题 |
| 全屏 | 全屏模式 |

## 审阅模式

当执行批注命令时，查看器自动进入**审阅模式**。此时 DWG/DXF 背景变为只读，所有批注和测量作为叠加层显示。退出批注命令后，仍保持在审阅模式，直到手动切换回编辑模式。

审阅模式下，批注命令自动可用；编辑模式下，批注工具需要手动激活。
