# 审阅模式

审阅模式在只读模式的基础上增加了完整的批注功能。DWG/DXF 背景保持只读，所有批注以 HTML 叠加层形式绘制，通过 sidecar JSON 文件独立保存和分享。

进入审阅模式后，界面自动显示批注相关的工具和面板。

## 桌面端

### 整体布局

与只读模式相同：没有 Ribbon 功能区和状态栏，以画布为中心，命令通过右侧工具栏和停靠面板进入。区别在于右侧工具栏多出批注工具组，停靠面板多出审阅面板。

<ReviewModeLayout mode="review" />


### 右侧工具栏

在只读模式的基础上，多出一个**批注工具组**弹出面板，包含：箭头、文字、云线、矩形、圆、标注（Callout）、印章等批注命令。

### 停靠面板

在只读模式的基础上，多出一个**审阅（批注）面板**：

| 面板 | 说明 |
|---|---|
| 审阅（批注） | 列出所有批注，按类型显示图标、创建者、时间、摘要。支持点击定位、编辑元数据（Comment / Status）、清除 |

其余面板（图层、测量列表、实体信息、统计、缺失资源）与只读模式相同。

## 平板端（Pad）

与只读模式的平板端布局一致，但：

- 右侧工具栏多了批注工具组弹出面板按钮
- 停靠面板列表中多了"审阅"面板入口

## 手机端

手机端底部标签栏的 **Review 按钮**在此模式下激活可用。

### 底部标签栏

| 按钮 | 状态 |
|---|---|
| Zoom | 可用 |
| Measure | 可用 |
| Review | **可用** —— 点击弹出批注工具面板 |
| Layers | 可用 |
| Layout | 可用 |
| Setting | 可用 |

<MobileBottomTabBar mode="review" />


### Review 按钮

点击 Review 按钮后，底部弹出批注工具面板，列出：箭头、文字、云线、矩形、圆、标注（Callout）、印章等。选择后直接进入批注命令，画布上实时预览并支持交互创建。

### 批注列表

在 Review 面板的底部或二级视图中，可以查看当前图纸上的所有批注。点击列表项可以：

- 将画布缩放到该批注位置
- 切换批注可见性
- 打开批注元数据编辑（Comment / Status）

### 导入 / 导出批注

在 Review 面板顶部提供导出和导入按钮。sidecar JSON 文件可跨图纸、跨设备分享。

## 与只读模式的差异总结

| 组件 | 只读模式 | 审阅模式 |
|---|---|---|
| 右侧工具栏 · 批注工具组 | ✗ | ✓ |
| 停靠面板 · 审阅（批注） | ✗ | ✓ |
| 手机端 · Review 底部按钮 | 禁用（灰色） | 可用 |
| 批注创建 / 编辑 | ✗ | ✓ |
| 批注导入 / 导出 | ✗ | ✓ |
