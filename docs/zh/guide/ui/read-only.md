# 只读模式

只读模式用于纯粹地查看和测量图纸。DWG/DXF 背景完全不可修改，批注、绘制、修改等命令均不可用。

进入只读模式后，界面会根据设备类型自动适配布局。

## 桌面端

### 整体布局

只读模式没有 Ribbon 功能区和状态栏，界面以画布为中心，所有命令通过右侧工具栏和停靠面板进入：

```
┌──────────────────────────────────────────────────────┐
│                                                      │
│                                                      │
│                  画布 + 叠加层                         │
│                                                      │
│    ┌────┐                                            │
│    │右侧 │                                            │
│    │工具 │   停靠面板（图层、测量列表、实体信息等）      │
│    │栏  │                                            │
│    └────┘                                            │
│                                                      │
└──────────────────────────────────────────────────────┘
```

### 右侧工具栏

浮动在画布右侧的垂直工具栏，是只读模式下的主要命令入口：

- 选择 / 取消选择
- 平移（手形）
- 缩放到全图
- 窗口缩放
- 图层管理（打开面板）
- 测量工具组（弹出测量面板）
- 阅读模式（进入全屏专注模式）
- 切换明/暗背景

### 停靠面板

| 面板 | 说明 |
|---|---|
| 图层 | 列出所有图层，支持开/关、锁定、冻结、隔离 |
| 测量列表 | 列出当前图纸中所有测量项，点击可定位 |
| 实体信息 | 选中实体后显示其类型、坐标、图层、属性等 |
| 统计 | 块使用情况统计 |
| 缺失资源 | 提示缺失的字体或外部参照 |

## 平板端（Pad）

平板端采用介于桌面和手机之间的紧凑布局：

- 右侧工具栏保留，但按钮间距加大，便于触摸操作
- 停靠面板默认折叠为图标栏，点击展开为侧边抽屉

## 手机端

手机端采用**底部标签栏 + 抽屉面板**的设计，把所有交互集中到屏幕下方，上方留给画布。

### 底部标签栏

屏幕底部显示六个图标按钮：

```
┌──────┬─────────┬────────┬────────┬────────┬─────────┐
│ Zoom │ Measure │ Review │ Layers │ Layout │ Setting │
└──────┴─────────┴────────┴────────┴────────┴─────────┘
```

| 按钮 | 功能 |
|---|---|
| Zoom | 缩放工具组：放大、缩小、缩放到全图、窗口缩放 |
| Measure | 测量工具组：测长度、连续测、测面积、测坐标、测弧长、测角度 |
| Review | 批注入口（只读模式下禁用，灰色） |
| Layers | 打开图层面板抽屉 |
| Layout | 切换布局 |
| Setting | 设置菜单：主题、模拟鼠标、OSNAP 等 |

### 抽屉面板

点击 Layers 按钮会从底部弹出图层面板，显示各图层的名称、可见性（On/Off）、颜色等。点击画布或面板外区域关闭抽屉。

### 画布区域

画布占满屏幕上方，选中测量后会在画布上显示测量徽章。

### 与桌面端的差异

手机端不显示右侧工具栏和停靠面板，对应功能改为底部标签栏 + 抽屉面板的形式。
