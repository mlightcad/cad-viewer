# 读写模式

读写模式（Write）是功能最完整的模式。除了审阅模式的全部能力外，还支持直接在 DWG/DXF 上创建、编辑、删除实体——让 Web 产品承载真实的绘图工作，而不只是只读预览。

默认打开文件时使用读写模式，除非调用时显式指定了只读或审阅模式。

### 顶部功能区

Ribbon 完整展示 AutoCAD 风格的所有选项卡：

| 选项卡 | 包含命令 |

| 修改 | Move、Copy、Offset、Trim、Extend、Rotate、Scale、Mirror、Array 等 |

| 批注 | 全部批注命令 |

### 命令行

画布底部有一个命令行窗口，可以直接键入命令名（如 `L` 回车画直线、`C` 回车画圆），支持：
- 显示命令提示和历史
- 输入数值、坐标
- 上下箭头遍历历史命令

## 平板端（Pad）

Pad 端布局介于桌面和手机之间，但读写模式下会尽量保留编辑所需的完整组件：

- Ribbon 保留完整选项卡，但命令按钮折叠为图标
- 右侧工具栏保留
- 命令行默认折叠为一个小条，点击展开
- 停靠面板可展开为侧边抽屉
- 状态栏精简显示核心按钮

## 手机端

手机端进入读写模式时，命令行和完整的绘制/修改功能通过**移动端命令覆盖层**（Mobile Command Overlay）实现，不再使用底部标签栏。

### 命令覆盖层

执行绘制或修改命令时，屏幕底部显示一个命令操作条，包含：
- 当前命令提示
- ✓ 确认 / ✗ 取消 按钮
- 动态输入（DYN）弹出面板

### 输入方式

手机端绘图采用以下输入方式：
- **单击点输入**：轻点屏幕（<0.5s），创建一个点
- **拖动点输入**：长按屏幕（>0.5s），进入拖动选取模式后抬起
- **模拟鼠标**：默认开启，长按后手指上方出现十字光标，实际输入位置以十字光标为准
- **放大镜**：可在设置中切换，圆形放大镜 HUD 放大手指区域

### 自动返回

命令执行过程中，状态栏暂时隐藏（由命令覆盖层接管输入）。命令结束后恢复显示。
