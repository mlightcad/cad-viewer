# 会话附件

**会话附件（Session Accessory）** 是一类动态挂载到 UI 上的小型控件组，用来在特定时机为用户提供额外的操作入口。它的核心特点是——**只在需要的时候出现，不需要的时候自动消失**。

会话附件主要应用在以下两种场景：

- **移动端**：移动端没有桌面端那样的 Ribbon UI，很多在 Ribbon 上的命令选项无法直接展示。会话附件可以在命令执行中或对象被选中时，把相关选项带到用户手边。
- **无 Ribbon UI 的运行时**：某些嵌入式或轻量运行时不提供 Ribbon 组件，会话附件同样可以作为补充 UI 来使用。

会话附件分为两种类型——**命令会话附件**和**选择会话附件**。

## 命令会话附件

命令会话附件在**命令执行过程中**由命令安装，为当前命令提供一些额外的 UI 控件。命令结束或取消后，命令会话附件会自动隐藏。

典型的例子是**测量 / 批注命令**安装的**绘图样式附件（Draw-style Accessory）**——在执行测量、添加批注等命令时，会话面板的第一行会出现颜色选择、文字大小等按钮，让用户在绘制过程中可以随时调整外观，而不必中断命令去 Ribbon 上寻找。

## 选择会话附件

选择会话附件在**选中一个或多个图形对象**时出现，挂载在**快捷工具栏（Shortcut Toolbar）** 的左侧，并通过一条竖线与右侧的快捷操作按钮分隔。当取消选择后，选择会话附件会自动消失。

选择会话附件的作用与命令会话附件类似——为被选中的对象提供上下文化的操作入口。比如选中一段批注文字时，选择会话附件可以提供颜色、字号等调整控件。

## 两种会话附件的对比

| 特性 | 命令会话附件 | 选择会话附件 |
|---|---|---|
| **出现时机** | 命令执行过程中 | 选中一个或多个对象时 |
| **挂载位置** | 移动端：会话面板第一行<br/>无 Ribbon 环境：命令 UI 区 | 快捷工具栏左侧 |
| **消失条件** | 命令结束或取消 | 取消选择 |
| **典型控件** | 颜色、文字大小、其他命令专属选项 | 颜色、文字大小、对象属性编辑 |
| **是否必有** | 否，由命令决定 | 否，取决于选中对象的类型 |

## 与桌面端 Ribbon 的关系

在桌面端，命令相关的选项通常集中在 Ribbon 的"上下文选项卡"里——当某个命令激活时，Ribbon 会自动切换到该命令对应的选项卡。会话附件本质上是**移动端 / 无 Ribbon 场景下，对上下文选项卡的一种轻量化替代**：

| 桌面端 | 移动端 / 无 Ribbon |
|---|---|
| Ribbon 上下文选项卡 | 命令会话附件（在会话面板中） |
| Ribbon 常规选项卡上的对象属性面板 | 选择会话附件（在快捷工具栏中） |
