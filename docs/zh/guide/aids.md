# 辅助显示

辅助显示帮助你更精确地定位点、方向和对象。

## 对象捕捉（OSNAP）

对象捕捉会在光标靠近可捕捉位置时，自动吸附到这些点上，并显示捕捉标记。

支持的捕捉模式：

| 模式 | 标记 | 说明 |
|---|---|---|
| EndPoint | 矩形 | 线段端点 |
| MidPoint | 三角形 | 线段中点 |
| Center | 圆形 | 圆/圆弧/椭圆圆心 |
| Quadrant | 菱形 | 圆的四个象限点 |
| Nearest | 十字 | 离光标最近的点 |
| Intersection | × | 两条线的交点 |

OSNAP 在状态栏上可以快速开关，点击可以进入详细配置面板选择要启用的捕捉模式。

## 正交模式（ORTHO）

开启后，限制下一条线只能沿水平或垂直方向绘制。适用于绘制轴对齐的矩形、正三角形等。

- 快捷键：`F8`（如果支持）
- 状态栏点击切换开关

## 极轴跟踪（POLAR）

开启后，光标会沿设定的角度增量方向自动对齐。默认角度增量为 90°，可选择 5°、10°、15°、18°、22.5°、30°、45° 或 90°。

极轴和正交互斥：打开正交会自动关闭极轴，反之亦然。

## 动态输入（DYN）

在光标附近显示浮动输入框。命令执行过程中，可以直接在输入框里键入数值（距离、角度等）而不必操作命令行。

## 橡皮筋预览

几乎所有绘图命令在你移动光标时，都会实时显示一条从"上一个点"到"当前光标"的临时预览线段（橡皮筋），帮助你判断方向和长度。
