# طرق التشغيل

## المكتبي (الماوس)

| العملية | التأثير |
|---|---|
| نقرة يسرى | التقاط نقطة / اختيار كيان |
| سحب يسار | تحديد إطار / سحب كيان |
| عجلة التمرير | تكبير/تصغير العرض |
| الزر الأوسط أو Shift + سحب الزر الأوسط | تحريك العرض |
| الزر الأيمن | خارج الأمر: إظهار قائمة السياق؛ داخل الأمر: يكافئ Enter للتأكيد |
| Esc | إلغاء الأمر الحالي |
| Enter / مسافة | تأكيد الخطوة الحالية أو تكرار الأمر السابق |
| Ctrl + Z | تراجع |
| Ctrl + Y | إعادة |

## المتنقل (اللمس)

### وضع التصفح

يدعم الإيماءات التالية عند عرض الرسم:

| الإيماءة | التأثير |
|---|---|
| تحريك بإصبع واحد | اللمس بإصبع واحد على منطقة الرسم وتحريكه، يغيّر موضع الرسم |
| تحريك بإصبعين | اللمس بإصبعين على منطقة الرسم مع الحفاظ على المسافة بينهما، يغيّر موضع الرسم |
| قرص بإصبعين | تغيير المسافة بين الإصبعين، يكبّر أو يصغّر العرض |

### وضع التحرير

في حالة الرسم والتحرير، بالإضافة إلى إيماءات التصفح، يُدعم ما يلي:

| الإيماءة | التأثير |
|---|---|
| نقرة بإصبع واحد | عند الرسم، تنشئ النقرة نقطة؛ بدون أمر، اختيار الكيان بالنقر عليه |
| ضغط طويل بإصبع واحد + انزلاق | تحديد بإطار / تحديد متقاطع |
| نقرة بإصبع واحد + انزلاق | عند إنشاء كيان، بعد تحديد نقطة يمكن سحبها لإعادة ضبط موضعها؛ عند تحرير كيان، النقر على grip المحدد ثم سحبه ينفذ تمديد grip أو تحجيمه |
| إدخال بنقرة | نقرة خفيفة بإصبع واحد على الشاشة—بدون إزاحة ورفع سريع (أقل من 0.5 ثانية)—تُدخل نقطة |
| إدخال بسحب | الضغط المطوّل بإصبع واحد على الشاشة لأكثر من 0.5 ثانية، يدخل وضع التحديد بالسحب، ثم الرفع بعد التحرك إلى الموضع المستهدف يُكمل الإدخال |

### اتجاه تحديد الإطار

كما في AutoCAD، يحدد اتجاه تحديد الإطار وضع التحديد:

- **من اليسار إلى اليمين**: تحديد نافذة—تُختار فقط الكيانات الموجودة بالكامل داخل المستطيل
- **من اليمين إلى اليسار**: تحديد متقاطع—تُختار جميع الكيانات المتقاطعة مع المستطيل
