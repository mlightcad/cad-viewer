# وضع المراجعة

يُضيف وضع المراجعة قدرات ترميز كاملة فوق وضع القراءة فقط. تبقى خلفية DWG/DXF للقراءة فقط؛ تُرسم جميع الترميزات كـ HTML overlays وتُحفظ/تُشارَك بشكل مستقل عبر ملفات JSON جانبية.

عند الدخول إلى وضع المراجعة، تعرض الواجهة تلقائيًا الأدوات واللوحات المرتبطة بالترميز.

## سطح المكتب

### التخطيط العام

نفس وضع القراءة فقط: لا Ribbon ولا شريط حالة. تتمحور الواجهة حول اللوحة، ويتم الوصول إلى الأوامر عبر شريط الأدوات على الجانب الأيمن واللوحات المثبتة. الفرق هو أن شريط الأدوات على الجانب الأيمن يكتسب مجموعة أدوات ترميز، واللوحات المثبتة تكتسب لوحة مراجعة.

### شريط الأدوات على الجانب الأيمن

بالإضافة إلى أدوات وضع القراءة فقط، توجد لوحة منبثقة **لمجموعة أدوات الترميز** تحتوي على: سهم، نص، سحابة، مستطيل، دائرة، Callout، ختم، وأوامر ترميز أخرى.

### اللوحات المثبتة

بالإضافة إلى لوحات وضع القراءة فقط، توجد **لوحة المراجعة (الترميز)**:

| اللوحة | الوصف |
|---|---|
| Review (Markup) | يسرد جميع الترميزات، مع عرض الأيقونة، المنشئ، الوقت، والملخص حسب النوع. يدعم النقر للتحديد، وتحرير البيانات الوصفية (تعليق / حالة)، والمسح |

جميع اللوحات الأخرى (Layers, Measurements, Entity Info, Statistics, Missing Resources) هي نفسها كما في وضع القراءة فقط.

## الجهاز اللوحي (Pad)

نفس تخطيط الجهاز اللوحي كما في وضع القراءة فقط، لكن:

- يكتسب شريط الأدوات على الجانب الأيمن زرًا منبثقًا لمجموعة أدوات الترميز
- تكتسب قائمة اللوحات المثبتة مدخل لوحة "Review"

## الجوال

يكون زر **Review** في شريط علامات الجوال السفلي نشطًا ومتاحًا في هذا الوضع.

### شريط علامات سفلي

| الزر | الحالة |
|---|---|
| Zoom | متاح |
| Measure | متاح |
| Review | **متاح** — انقر لفتح لوحة أدوات الترميز |
| Layers | متاح |
| Layout | متاح |
| Setting | متاح |

### زر المراجعة

النقر على زر Review يُظهر لوحة أدوات ترميز من الأسفل، تسرد: سهم، نص، سحابة، مستطيل، دائرة، Callout، ختم، إلخ. اختيار واحد يدخل مباشرة إلى أمر الترميز، مع معاينة في الوقت الفعلي على اللوحة وإنشاء تفاعلي.

### قائمة الترميز

في أسفل لوحة Review أو في عرض ثانوي، يمكنك رؤية جميع الترميزات على الرسم الحالي. النقر على عنصر في القائمة يسمح لك بـ:

- تكبير اللوحة إلى موقع الترميز
- تبديل ظهور الترميز
- فتح تحرير البيانات الوصفية للترميز (تعليق / حالة)

### استيراد / تصدير الترميز

يوفر أعلى لوحة Review أزرار تصدير واستيراد. يمكن مشاركة ملفات JSON الجانبية عبر الرسومات والأجهزة.

## الاختلافات عن وضع القراءة فقط

| المكوّن | القراءة فقط | المراجعة |
|---|---|---|
| شريط الأدوات الأيمن · مجموعة أدوات الترميز | ✗ | ✓ |
| اللوحة المثبتة · Review (Markup) | ✗ | ✓ |
| الجوال · زر Review السفلي | معطّل (رمادي) | متاح |
| إنشاء / تحرير الترميز | ✗ | ✓ |
| استيراد / تصدير الترميز | ✗ | ✓ |
