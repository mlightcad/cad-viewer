# نظرة عامة على ميزة البرنامج النصي

تُستخدم ميزة البرنامج النصي لتنفيذ كود JavaScript مخصص على الرسم، لإجراء عمليات الاستعلام والإحصاء والتحرير الجماعي والتحديد والتمييز. يتفاعل البرنامج النصي مع الرسم من خلال الكائن `cad`، دون الحاجة إلى الاتصال بنموذج خارجي أو إعداد مفتاح API.

ميزة البرنامج النصي مُقدَّمة من خلال البرنامج المساعد `@mlightcad/cad-script-plugin`. لا تتوفر لوحة البرنامج النصي إلا بعد تحميل هذا البرنامج المساعد في تطبيقك.

## فتح لوحة البرنامج النصي

- اكتب `cadscript` في سطر الأوامر واضغط Enter
- أو انقر على علامة التبويب «البرنامج النصي» في لوحة الأدوات

تحتوي لوحة البرنامج النصي على:
- **محرر البرنامج النصي**: لكتابة جسم دالة JavaScript
- **زر التشغيل**: لتنفيذ البرنامج النصي (الاختصار `Ctrl+Enter`)
- **المساعدة**: يفتح هذا الشرح باللغة الحالية
- **منطقة النتائج**: تعرض القيمة المُعادة كشجرة JSON قابلة للطي، مع السجلات والأخطاء وتغييرات الكيانات. اسحب الفاصل بين المحرر وهذه المنطقة لتغيير الارتفاع.

## طريقة تنفيذ البرنامج النصي

يعمل البرنامج النصي في الوضع الصارم، ويتم تغليفه تلقائيًا كدالة:

```javascript
function __cadScript(cad) {
  // 你的代码写在这里
}
```

المعامل الوحيد للدالة هو `cad`، ومن خلاله يمكنك الوصول إلى بيانات الرسم وتنفيذ العمليات.

## القيود

- للبرنامج النصي حدود زمنية وحدود لعدد الخطوات، ويُوقف تلقائيًا عند تجاوزها
- يُحظر الوصول إلى الكائنات العامة للصفحة (`window` و`document` و`fetch` وغيرها)
- يُحظر استخدام صيغ مثل `import` / `export` / `this`
- يجب أن تكون القيمة المُعادة قابلة للتسلسل بصيغة JSON
- يجب تنفيذ عمليات التحرير داخل `cad.edit.transaction`، وأن يكون الرسم في حالة قابلة للتحرير

## حفظ المسودة

يُحفظ محتوى المحرر تلقائيًا في التخزين المحلي للمتصفح، وبعد تحديث الصفحة يُستعاد آخر برنامج نصي تم تحريره.
