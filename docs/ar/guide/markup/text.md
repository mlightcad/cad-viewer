# النص

ضع تسمية نصية خالصة في موضع محدد، دون خط قائد.

## خطوات التفاعل

1. انقر لاختيار موضع وضع النص
2. أدخل النص في مربع التحرير المضمّن المنبثق
3. انقر في موضع آخر أو اضغط **Esc** للإنهاء

بعد الإنشاء، يمكن سحب grip المركزي لتحريك النص بالكامل. النقر المزدوج يتيح تحرير محتوى النص مرة أخرى.
