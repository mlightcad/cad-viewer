# خط السحابة (سحابة المراجعة)

ارسم إطار سحابة مستطيل، يُستخدم غالبًا لتحديد المناطق التي تحتاج إلى تعديل.

## خطوات التفاعل

1. انقر لاختيار الزاوية الأولى
2. انقر لاختيار الزاوية المقابلة—معاينة لحظية لحدود السحابة
3. بعد الاكتمال، يمكن اختيار إضافة Callout (خط قائد + فقاعة نصية) للسحابة
