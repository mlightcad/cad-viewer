# نظرة عامة على التعليقات

تُستخدم أوامر التعليقات لإضافة علامات المراجعة على الرسم. عند تنفيذ أمر التعليق، يدخل العارض تلقائيًا **وضع المراجعة** (خلفية DWG/DXF للقراءة فقط).

تُرسم جميع التعليقات كطبقة تراكب HTML، **ولا تُعدّل ملف DWG/DXF الأصلي**. تُحفظ وتُشارك بشكل مستقل عبر ملف JSON sidecar (`اسم الرسم.markup.json`).

## إنشاء تعليق

تستخدم معظم أوامر التعليقات تفاعل النقر الموزّع بنمط CAD:

1. اختيار الأمر (الشريط العلوي → مجموعة التعليقات، أو لوحة التعليقات المنبثقة في شريط الأدوات الأيمن)
2. النقر على النقاط المطلوبة بالتسلسل وفقًا لتعليمات الأمر
3. توجد معاينة لحظية أثناء السحب (Jig)
4. بعد الاكتمال، يظهر التعليق فورًا على لوحة الرسم

## تحرير التعليق

- **نقرة** على التعليق لاختياره وإظهار نقاط grip للتحرير
- **سحب نقطة grip** يمكنه ضبط الشكل، النقاط الطرفية، إلخ
- **نقر مزدوج** على التعليقات النصية (نص، Callout، أشكال بها Callout إضافي) يدخل تحرير النص المضمّن
- بعد الاختيار، اضغط **Delete** للحذف

## تراجع / إعادة

تدعم عمليات التعليق التراجع والإعادة. لا يتراجع التراجع فقط عن عملية الإنشاء، بل يتراجع أيضًا عن تحرير grip والحذف والتعديلات الأخرى.

## استيراد / تصدير

- **تصدير**: تصدير جميع التعليقات الحالية كملف JSON للتنزيل
- **استيراد**: تحميل ملف JSON المُصدّر سابقًا، واستعادة جميع التعليقات

يمكن مشاركة ملف JSON sidecar عبر الرسومات والأجهزة.
