# واجهة المستخدم

يستخدم MLightCAD Viewer تخطيطًا كلاسيكيًا من ثلاثة أجزاء مشابهًا لـ AutoCAD: الشريط العلوي في الأعلى، ومنطقة لوحة الرسم في الوسط، وشريط الحالة في الأسفل.

## التخطيط العام

```
┌───────────────────────────────────────────────┐
│  الشريط العلوي (Ribbon)                       │
├───────────────────────────────────────────────┤
│                                               │
│           لوحة الرسم + الطبقات الراسية         │
│    ┌─────┐                                    │
│    │شريط│  اللوحات الراسية (الطبقات، الخصائص)   │
│    │الأدوات│                                  │
│    │الأيمن│                                   │
│    └─────┘                                    │
│                                               │
├───────────────────────────────────────────────┤
│  شريط الحالة                                  │
└───────────────────────────────────────────────┘
```

## الشريط العلوي

ينظّم الشريط العلوي أزرار الأوامر في صورة علامات تبويب (Tab) ومجموعات (Group).

### ملف

| الزر | الوصف |
|---|---|
| فتح | فتح ملفات DWG / DXF |
| تصدير DXF | تصدير الرسم الحالي إلى صيغة DXF |
| تصدير PNG | تصدير لوحة الرسم كصورة PNG |

### رسم

يحتوي على أوامر رسم مثل Line وCircle وArc وRect وPolyline وHatch. هذه الأوامر غير متاحة في وضع المراجعة.

### الطبقات

عمليات الطبقات مثل التشغيل/الإيقاف، التجميد/الإذابة، القفل، العزل وغيرها.

### تعديل

أوامر التعديل مثل Move وCopy وOffset.

### قياس

المسافة، الزاوية، المساحة، طول القوس، القياس المستمر، إحداثيات النقطة. راجع [نظرة عامة على القياس](/ar/guide/measure/overview).

### تعليقات

السهم، خط السحابة، المستطيل، الدائرة، النص، التعليق التوضيحي (Callout)، التمييز، الأختام وغيرها. راجع [نظرة عامة على التعليقات](/ar/guide/markup/overview).

## شريط الأدوات الأيمن

شريط أدوات عمودي عائم على يمين لوحة الرسم، يوفر وصولاً سريعًا للأدوات الشائعة:

- **تحديد**: اختيار الكيانات وتحريكها
- **تحريك**: سحب لتحريك العرض
- **تكبير الكل**: توسيط جميع الرسومات
- **تكبير الإطار**: تحديد إطار للتكبير
- **إدارة الطبقات**: فتح لوحة الطبقات
- **تبديل الخلفية**: التبديل بين خلفية فاتحة/داكنة
- **وضع القراءة**: الدخول في وضع ملء الشاشة للقراءة المركّزة
- **مجموعة أدوات القياس**: إظهار لوحة أدوات القياس
- **مجموعة أدوات التعليقات**: إظهار لوحة أدوات التعليقات (تظهر في وضع المراجعة)

## اللوحات الراسية

يمكن إرساء اللوحات على يمين لوحة الرسم أو سحبها كنوافذ عائمة. اللوحات الشائعة:

| اللوحة | الوصف |
|---|---|
| الطبقات | تعرض جميع الطبقات، وتدعم التشغيل/الإيقاف، القفل، التجميد، العزل وغيرها |
| الخصائص | تعرض معلومات خصائص الكيان المحدد |
| قائمة القياسات | تعرض جميع عمليات القياس في الرسم الحالي، النقر عليها يحدد موقع القياس المناسب |
| المراجعة (التعليقات) | تعرض جميع التعليقات، وتدعم تحرير بيانات التعليقات الوصفية والمسح وغيرها |
| الإحصاء | إحصاء استخدام الكتل في الرسم |
| الموارد المفقودة | تنبيه بالخطوط أو المراجع الخارجية المفقودة في الرسم |

## شريط الحالة

يقع شريط الحالة في أسفل الواجهة، ومن اليسار إلى اليمين:

| المنطقة | الوصف |
|---|---|
| علامات التخطيط | التبديل بين مساحة النموذج / التخطيطات |
| الإحداثيات | عرض إحداثيات مؤشر الموضع الحالي (للمكتبي فقط) |
| OSNAP | تشغيل/إيقاف وضع الالتقاط الكائني وإعداده |
| ORTHO | مفتاح الوضع المتعامد |
| POLAR | مفتاح التتبع القطبي وزاوية الزيادة |
| عرض سُمك الخط | التحكم في عرض سُمك الخط |
| الإدخال الديناميكي | مفتاح الإدخال الديناميكي |
| تبديل السمة | سمة فاتحة/داكنة |
| ملء الشاشة | وضع ملء الشاشة |

## وضع المراجعة

عند تنفيذ أمر تعليق، يدخل العارض تلقائيًا **وضع المراجعة**. عندها تصبح خلفية DWG/DXF للقراءة فقط، وتُعرض جميع التعليقات والقياسات كطبقة تراكب. بعد الخروج من أمر التعليق، يبقى في وضع المراجعة حتى يُبدّل يدويًا إلى وضع التحرير.

في وضع المراجعة، تصبح أوامر التعليق متاحة تلقائيًا؛ وفي وضع التحرير، يجب تفعيل أدوات التعليق يدويًا.
