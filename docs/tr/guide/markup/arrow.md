# Ok

İki nokta arasına ok uçlu bir çizgi parçası çizer.

## Etkileşim Adımları

1. Okun başlangıç noktasını seçmek için tıkla
2. Okun bitiş noktasını seçmek için tıkla — çizgi parçası ve ok yönü gerçek zamanlı olarak önizlenir

Oluşturulduktan sonra uç noktalar sürüklenerek ok konumu ve yönü ayarlanabilir.
