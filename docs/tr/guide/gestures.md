# Jestler

## Masaüstü (Fare)

| İşlem | Sonuç |
|---|---|
| Sol tık | Nokta seç / varlık seç |
| Sol sürükle | Pencere seçimi / varlığı sürükle |
| Tekerlek | Görünümü yakınlaştır |
| Orta veya Shift + Orta sürükle | Görünümü kaydır |
| Sağ tık | Komut dışında: bağlam menüsü açar; komut sırasında: Enter yerine geçer |
| Esc | Geçerli komutu iptal et |
| Enter / Boşluk | Geçerli adımı onayla veya son komutu tekrarla |
| Ctrl + Z | Geri al |
| Ctrl + Y | Yinele |

## Mobil (Dokunmatik)

### Gezinme modu

Çizimi görüntülerken aşağıdaki jestler desteklenir:

| Jest | Sonuç |
|---|---|
| Tek parmak kaydır | Çizim alanına tek parmakla dokun ve hareket ettir; çizim konumunu değiştirir |
| İki parmak kaydır | Çizim alanına iki parmakla dokun, parmaklar arası mesafeyi koruyarak hareket ettir; çizim konumunu değiştirir |
| İki parmak kıstır | İki parmak arasındaki mesafeyi değiştir; görünümü yakınlaştır veya uzaklaştır |

### Düzenleme modu

Çizim ve düzenleme durumunda, gezinme jestlerine ek olarak aşağıdakiler de desteklenir:

| Jest | Sonuç |
|---|---|
| Tek parmak dokunuş | Çizim sırasında dokunuş bir nokta oluşturur; komut dışı durumda, nesneye dokunmak onu seçer |
| Tek parmak basılı tut + kaydır | Pencere / kesişim pencere seçimi |
| Tek parmak dokunuş + kaydır | Varlık oluştururken, işaretlenen noktaya dokunup kaydırarak o noktanın konumunu yeniden ayarla; nesne düzenlerken, seçili tutamaca dokunup sürükleyerek tutamca germe veya ölçeklendirme gerçekleştir |
| Dokunuş noktası girişi | Ekrana tek parmakla hafifçe dokun — yer değiştirme olmadan, hızlıca kaldır (0,5 saniyeden kısa) — bir nokta gir |
| Sürükleme noktası girişi | Ekrana tek parmakla 0,5 saniyeden uzun basılı tut, sürükleme seçim moduna gir, hedef konuma taşı ve kaldırarak girişi tamamla |

### Pencere seçimi yönü

AutoCAD'de olduğu gibi, pencere seçiminin yönü seçim modunu belirler:

- **Soldan sağa**: Pencere seçimi — yalnızca dikdörtgenin tamamen içinde kalan varlıklar seçilir
- **Sağdan sola**: Kesişim seçimi — dikdörtgenle kesişen tüm varlıklar seçilir
