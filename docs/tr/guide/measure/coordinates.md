# Koordinat Ölçümü

Belirtilen noktanın X / Y koordinatlarını ölçer.

## Etkileşim Adımları

1. Hedef noktayı seçmek için tıkla (OSNAP ile uç noktalar, kesişimler vb. kesin olarak yakalanabilir)

## Görüntüleme

Noktanın yanında `X xxx.xx  Y yyy.yy` biçiminde koordinat rozeti görüntülenir.
